# Generalized coordinate

↑ **Parent:** [Lagrangian](lagrangian.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Generalized_coordinate)

The variables of the [Lagrangian](lagrangian.md), e.g. the angles of a [double pendulum](double-pendulum.md). From that example it is clear that these variables don't need to be simple things like [cartesian coordinates](cartesian-coordinate-system.md) or [polar coordinates](polar-coordinate-system.md) (although these tend to be the overwhelming majority of simple case encountered): any way to describe the system is perfectly valid.

In [quantum field theory](quantum-field-theory-split.md), those variables are actually fields.
