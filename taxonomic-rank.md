# Taxonomic rank

↑ **Parent:** [Taxonomy](taxonomy-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Taxonomic_rank)

Naming taxonomic ranks like [genus](genus.md), [domain](domain-biology.md), etc. is a fucking waste of time, only useful before we developed [molecular biology](molecular-biology-split.md).

All that matters is the tree of [clades](clade.md) with examples of species in each clade, and common characteristics shared by the clade.

And with [molecular biology](molecular-biology-split.md), we can build those trees incredibly well for [extant](extant.md) species. When [extinct](extinct.md) species are involved however, things get more complicated.
