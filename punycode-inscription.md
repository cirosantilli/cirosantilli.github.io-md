# Punycode inscription

↑ **Parent:** [Inscription (blockchain)](inscription-blockchain.md)

[Namecoin](namecoin.md) examples are catalogued at: [https://punycodes.xyz](https://punycodes.xyz). The are small [Unicode art](unicode-art.md) or emoji code.

There seems to be nothing of particular artistic value as far as we've seen so far, the only interest in such tokens seems to be that:
- there are some examples that came earlier than those in the [Bitcoin](bitcoin.md) blockchain, notably a bit earlier than [Section "BitLen"](cool-data-embedded-in-the-bitcoin-blockchain/len-sassaman-tribute.md)
- [Namecoin](namecoin.md) is a [NFT](non-fungible-token.md) system unlike [Bitcoin](bitcoin.md) which is fungible, so those assets are naturally tradable
