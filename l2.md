[$\LP$](lp-space.md) for $p == 2$.

$\LTwo$ is by far the most important of $\LP$ because it is [quantum mechanics states](mathematical-formulation-of-quantum-mechanics.md) live, because the total probability of being in any state has to be 1!

[$\LTwo$](l2.md) has some crucially important properties that other $\LP$ don't (TODO confirm and make those more precise):
- it is the only $\LP$ that is [Hilbert space](hilbert-space.md) because it is the only one where an inner product compatible with the metric can be defined:
  - [https://math.stackexchange.com/questions/2005632/l2-is-the-only-hilbert-space-parallelogram-law-and-particular-ft-gt](https://math.stackexchange.com/questions/2005632/l2-is-the-only-hilbert-space-parallelogram-law-and-particular-ft-gt)
  - [https://www.quora.com/Why-is-L2-a-Hilbert-space-but-not-Lp-or-higher-where-p-2](https://www.quora.com/Why-is-L2-a-Hilbert-space-but-not-Lp-or-higher-where-p-2)
- [Fourier basis is complete for $\LTwo$](fourier-basis-is-complete-for-l2.md), which is great for solving [differential equation](differential-equation.md)
