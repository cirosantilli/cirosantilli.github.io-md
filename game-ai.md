# Game AI

↑ **Parent:** [AI game](ai-game.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Artificial_intelligence_in_video_games)

Game AI is an [artificial intelligence](artificial-intelligence-split.md) that plays a certain game.

It can be either developed for [serious](serious-game.md) purposes (e.g. [AGI](artificial-general-intelligence.md) development in [AI games](ai-game.md)), or to make games for interesting for humans.
