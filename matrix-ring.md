# Matrix ring

↑ **Parent:** [Square matrix](square-matrix.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Matrix_ring)

The matrix ring of degree n $M_n$ is the set of all n-by-n square matrices together with the usual [vector space](vector-space.md) and [matrix multiplication](matrix-multiplication.md) operations.

This set forms a [ring](ring-mathematics.md).
