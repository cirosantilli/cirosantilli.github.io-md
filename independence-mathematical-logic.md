# Independence (mathematical logic)

↑ **Parent:** [Axiom](axiom.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Independence_(mathematical_logic))

A [theorem](theorem.md) is said to be independent from a set of [axioms](axiom.md) if it cannot be proven neither true nor false from those axioms.

It or its negation could therefore be arbitrarily added to the set of axioms.
