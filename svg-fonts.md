# SVG fonts

↑ **Parent:** [SVG tutorial](svg-tutorial.md)

The major problem with SVG is text [computer fonts](computer-font.md). If you make an image with text that depends on one [computer font](computer-font.md) and it is not present in the viewer's machine, it will use some other font, which may overlap with other elements of the image. Some libraries [Matplotlib](matplotlib.md) solve this [by writing characters as curves](https://stackoverflow.com/questions/34387893/output-matplotlib-figure-to-svg-with-text-as-text-not-curves), but this produces large files and unsearchable text. The inability of different computer platforms to standardize fonts that must always be present is a major issue.
