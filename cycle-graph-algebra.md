# Cycle graph (algebra)

↑ **Parent:** [Cayley graph](cayley-graph.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cycle_graph_(algebra))

How to build it: [https://math.stackexchange.com/questions/3137319/how-in-general-does-one-construct-a-cycle-graph-for-a-group/3162746#3162746](https://math.stackexchange.com/questions/3137319/how-in-general-does-one-construct-a-cycle-graph-for-a-group/3162746#3162746) good answer with [ASCII art](ascii-art.md). You basically just pick each element, and repeatedly apply it, and remove any path that has a longer version.

Immediately gives the [generating set of a group](generating-set-of-a-group.md) by looking at elements adjacent to the origin, and more generally the [order of each element](order-of-an-element-of-a-group.md).
