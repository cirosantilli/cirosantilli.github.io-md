# Classification of finite fields

↑ **Parent:** [Finite field](finite-field.md)  
🏷️ **Tags:** [Classification (mathematics)](classification-mathematics.md)

There's exactly one field per [prime power](prime-power.md), so all we need to specify a field is give its order, notated e.g. as $GF(n)$.

Every element of a finite field satisfies $x^{order} = x$.

It is interesting to compare this result philosophically with the [classification of finite groups](classification-of-finite-groups.md): fields are more constrained as they have to have two operations, and this leads to a much simpler classification!
