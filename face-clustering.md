# Face clustering

↑ **Parent:** [Facial recognition system](facial-recognition-system.md)  
🏷️ **Tags:** [Cluster analysis](cluster-analysis.md)

Given multiple [images](image.md), decide how many people show up these images and when each person shows up.

One particular case of this is for [videos](video.md), where you also have a timestamp for each image, and way more data.
