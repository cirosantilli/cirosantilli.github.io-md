# Unable to lock screen on Ubuntu

↑ **Parent:** [Ubuntu 23.10](ubuntu-23-10.md)

Happened on [P14s](ciro-santilli-s-hardware/lenovo-thinkpad-p14s-gen4-amd.md) on [Ubuntu 23.10](ubuntu-23-10.md), which started with fresh Ubuntu 23.10 install.

However it did not happen on [Lenovo ThinkPad P51 (2017)](ciro-santilli-s-hardware/lenovo-thinkpad-p51-2017.md) also on [Ubuntu 23.10](ubuntu-23-10.md) which had been upgraded several times from God knows what starting point... At first one had X11 (forced by [Nvidia](nvidia.md) drivers) and the other Wayland, but moving to p14s X11 changed nothing.

Both were running [GNOME Display Manager](gnome-display-manager.md).

Same happens with Super + L, but also CLI commands: [https://askubuntu.com/questions/7776/how-do-i-lock-the-desktop-screen-via-command-line](https://askubuntu.com/questions/7776/how-do-i-lock-the-desktop-screen-via-command-line)
