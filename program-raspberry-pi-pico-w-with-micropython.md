# Program Raspberry Pi Pico W with MicroPython

↑ **Parent:** [Program Raspberry Pi Pico W with X](program-raspberry-pi-pico-w-with-x.md)  
🏷️ **Tags:** [MicroPython](micropython.md)

Install firmware: [https://projects.raspberrypi.org/en/projects/getting-started-with-the-pico/3](https://projects.raspberrypi.org/en/projects/getting-started-with-the-pico/3)

Then there are two appraoches:
- thonny if you like clicking mouse buttons:
  ```
  pipx install thonny
  ```

  and select the interpreter as the Pico.
- [ampy](ampy.md) if you like things to just run from the CLI: [How to run a MicroPython script from a file on the Raspberry Pi Pico W from the command line?](how-to-run-a-micropython-script-from-a-file-on-the-raspberry-pi-pico-w-from-the-command-line.md)
