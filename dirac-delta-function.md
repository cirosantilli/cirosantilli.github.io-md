# Dirac delta function

↑ **Parent:** [Distribution (mathematics)](distribution-mathematics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dirac_delta_function)

The "0-width" pulse [distribution](distribution-mathematics.md) that integrates to a step.

There's not way to describe it as a classical [function](function-mathematics.md), making it the most important example of a [distribution](distribution-mathematics.md).

Applications:
- [position operator](position-operator.md) in [quantum mechanics](quantum-mechanics-split.md). It's not a coincidence that the function is named after [Paul Dirac](paul-dirac.md).
