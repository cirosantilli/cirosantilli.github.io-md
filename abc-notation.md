# ABC notation

↑ **Parent:** [Computer music file format](computer-music-file-format.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/ABC_notation)

Standard from 2011: [http://abcnotation.com/wiki/abc:standard:v2.1](http://abcnotation.com/wiki/abc:standard:v2.1)

A decent way to write diatonic music as plaintext!

Conversion to [MIDI](midi.md) with [abcmidi](abcmidi.md).

No bend/vibratto/slides :-(

Multitrack volatile: [http://abcnotation.com/wiki/abc:standard:v2.1#multiple_voices](http://abcnotation.com/wiki/abc:standard:v2.1#multiple_voices)
