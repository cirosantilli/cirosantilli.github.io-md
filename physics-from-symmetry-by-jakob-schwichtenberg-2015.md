# Physics from Symmetry by Jakob Schwichtenberg (2015)

↑ **Parent:** [Jakob Schwichtenberg](jakob-schwichtenberg.md)

[https://www.amazon.com/Physics-Symmetry-Undergraduate-Lecture-Notes/dp/3319192000](https://www.amazon.com/Physics-Symmetry-Undergraduate-Lecture-Notes/dp/3319192000)

This is a good book. It is rather short, very direct, which is a good thing. At some points it is slightly too direct, but to a large extent it gets it right.

The main goal of the book is to basically to build the [Standard Model Lagrangian](standard-model-lagrangian.md) from only initial [symmetry](symmetry.md) considerations, notably the [Poincaré group](poincare-group.md) + [internal symmetries](internal-symmetry.md).

The book doesn't really [show how to extract numbers from that Lagrangian](doing-physics-means-calculating-a-number.md), but perhaps that can be pardoned, [do one thing and do it well](do-one-thing-and-do-it-well.md).
