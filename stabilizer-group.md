# Stabilizer (group)

↑ **Parent:** [Permutation group](permutation-group.md)

Suppose we have a given [permutation group](permutation-group.md) that acts on a set of n elements.

If we pick k elements of the set, the stabilizer subgroup of those k elements is a subgroup of the given permutation group that keeps those elements unchanged.

Note that an analogous definition can be given for non-finite groups. Also note that the case for all finite groups is covered by the permutation definition since [all groups are isomorphic to a subgroup of the symmetric group](all-groups-are-isomorphic-to-a-subgroup-of-the-symmetric-group.md)
