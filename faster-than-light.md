# Faster-than-light

↑ **Parent:** [Speed of light](speed-of-light.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Faster-than-light)

In [special relativity](special-relativity.md), it is impossible to travel faster than light.

One argument of why, is that if you could travel faster than light, then you could send a message to a point in [Spacetime](spacetime.md) that is [spacelike-separated](spacelike-separated-event.md) from the present. But then since the target is spacelike separated, there exists a [inertial frame of reference](inertial-frame-of-reference.md) in which that event happens before the present, which would be hard to make sense of.
