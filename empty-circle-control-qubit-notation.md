# Empty circle control qubit notation

↑ **Parent:** [Controlled quantum gate](controlled-quantum-gate.md)

Some authors use the convention of:
- filled black circle: conventional [controlled quantum gate](controlled-quantum-gate.md), i.e. operate if control qubit is active
- empty (White) circle: operate if control qubit is inactive
