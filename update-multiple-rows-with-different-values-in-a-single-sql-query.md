# Update multiple rows with different values in a single SQL query

↑ **Parent:** [UPDATE (SQL)](update-sql.md)

This happens when you calculate a bunch of values on your program, and then want to save the to SQL.

[Upsert](upsert.md) is an option, but it fails if you have a `NOT NULL` column: [Upsert with `NOT NULL` column](upsert-with-not-null-column.md)
