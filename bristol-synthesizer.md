# Bristol (synthesizer)

↑ **Parent:** [Software synthesizer](software-synthesizer.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bristol_(synthesizer))

Simulates vintage [hardware synthesizers](hardware-synthesizer.md), and includes some pretty complex ones!

Aims to show an UI that looks exactly like the synthesizers in question.

For example for the [Minimoog](minimoog.md) on [Ubuntu](ubuntu.md) 20.04:
```
sudo apt install bristol
startBristol -mini -alsa
```

This is a really good piece of software. You can search on [YouTube](youtube.md) how some classic synths, work, and the immediately start playing them!
