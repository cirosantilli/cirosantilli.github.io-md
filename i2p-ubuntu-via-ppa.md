# I2P [Ubuntu](ubuntu.md) via PPA

↑ **Parent:** [I2P on Ubuntu](i2p-on-ubuntu.md)

```
sudo apt-add-repository ppa:i2p-maintainers/i2p
sudo apt-get update
sudo apt-get install i2p
```

