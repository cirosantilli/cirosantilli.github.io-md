# Journals must require source code and data sets to publish

↑ **Parent:** [Replication crisis](replication-crisis.md)

It is understandable that you might not be able to reproduce a paper that does a [natural science](natural-science.md) experiment, given that [physics is brutal](deep-tech.md).

But for papers that have either [source code](source-code.md) or data sets, [academic journals](academic-journal.md) must require that those be made available, or refuse to publish.

Any document [without such obvious reproducibility elements](replication-crisis.md) is a [white paper](white-paper.md), not a proper [peer reviewed paper](peer-review.md).
