# Undecidability requires infinitely many inputs

↑ **Parent:** [Undecidable problem](undecidable-problem.md)

If there are infinitely many inputs, we can always construct a (potentially exponentially huge) [Turing machine](turing-machine.md) that hardcodes the outcome for every possible input, so the problem is never [undecidable](undecidable-problem.md).

The problem is of course deciding and proving the outcome for each possible input, notably as it is possible that calculation for some of the inputs may be [independent](independence-mathematical-logic.md) from [ZFC](zermelo-fraenkel-axioms-with-the-axiom-of-choice.md).
