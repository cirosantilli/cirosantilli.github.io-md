# Node (server)

↑ **Parent:** [Server (computing)](server-computing.md)

It runs one instance of the [Linux kernel](linux-kernel.md) and has one [IP address](ip-address.md). Each node is therefore a complete computer. As such is must also contain [RAM](random-access-memory.md) memory, [disk storage](disk-storage.md) and a [network interface controller](network-interface-controller.md).
