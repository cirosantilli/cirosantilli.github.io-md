# tshark

↑ **Parent:** [Wireshark](wireshark.md)

Sample usage:
```
sudo tshark -f 'host 192.168.1.102
```
This produces simple one liners for each request.

What you likely want is the `-V` option which fully disassembles each frame much as you can do in the [GUI](graphical-user-interface.md) [Wireshark](wireshark.md):
```
sudo tshark -V -f 'host 192.168.1.102
```
