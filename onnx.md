# ONNX

↑ **Parent:** [Deep learning framework](deep-learning-framework.md)  
🏷️ **Tags:** [Good](good.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/ONNX)

The most important thing this project provides appears to be the `.onnx` file format, which represents [ANN models](ann-model.md), pre-trained or not.

[Deep learning frameworks](deep-learning-framework.md) can then output such `.onnx` files for interchangeability and serialization.

Some examples:
- [activatedgeek/LeNet-5](activatedgeek-lenet-5.md) produces a trained `.onnx` from [PyTorch](pytorch.md)
- [MLperf v2.1 ResNet](mlperf-v2-1-resnet.md) can use `.onnx` as a pre-trained model

The cool thing is that [ONNX](onnx.md) can then run [inference](inference-ml.md) in an uniform manner on a variety of devices without installing the [deep learning framework](deep-learning-framework.md) used for. It's a bit like having a kind of portable executable. Neat.
