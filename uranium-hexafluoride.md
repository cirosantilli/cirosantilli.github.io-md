# Uranium hexafluoride

↑ **Parent:** [Uranium compound](uranium-compound.md)  
🏷️ **Tags:** [Fluorine compound](fluorine-compound.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Uranium_hexafluoride)

This is an important man-made [uranium compound](uranium-compound.md) as it is used in [uranium enrichment](enriched-uranium.md).

The main reason for this is that [fluorine](fluorine.md) only has one stable [isotope](isotope.md), which allows you to pick up weight differences in [uranium isotopes](uranium-isotope.md) in isolation.

Hex [sublimates](sublimation.md) at around 56.5 °C at so it can be converted to a gas relatively easily. It is then in its gas form that it is used for [uranium enrichment](enriched-uranium.md)
