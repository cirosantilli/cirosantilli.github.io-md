# Csound FLOSS manual

↑ **Parent:** [Csound](csound.md)

[https://flossmanual.csound.com/introduction/preface](https://flossmanual.csound.com/introduction/preface)

Very good open source book: [https://github.com/csound-flossmanual/csound-floss](https://github.com/csound-flossmanual/csound-floss)

Includes introduction to the basic [sound synthesis](sound-synthesis.md) and their implementation in [Csound](csound.md).

Examples run on browser via [Emscripten](emscripten.md) and just worked on [Ubuntu](ubuntu.md) 20.04!

Examples can also be downloaded all at once from: [http://www.csound-tutorial.net/floss_manual/](http://www.csound-tutorial.net/floss_manual/) Shame not in Git as standalone files.

[https://flossmanual.csound.com/sound-synthesis/subtractive-synthesis](https://flossmanual.csound.com/sound-synthesis/subtractive-synthesis) covers [Minimoog](minimoog.md)-like [subtractive synthesis](subtractive-synthesis.md).
