# Open PageRank implementation and data

↑ **Parent:** [PageRank](pagerank.md)

This section is about more "open" [PageRank](pagerank.md) implementations, notably using either or both of:
- [open source software](open-source-software.md)
- [open web crawling](open-web-crawling.md) data such as [Common Crawl](common-crawl.md)

As of 2025, the most open and reproducible implementation appears to be whatever [Common Crawl web graph official PageRank](common-crawl-web-graph-official-pagerank.md) does, which is to use [WebGraph](webgraph-software.md). It's quite beautiful.
