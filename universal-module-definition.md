# Universal Module Definition

↑ **Parent:** [JavaScript](javascript.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Universal_Module_Definition)

Since [JavaScript](javascript.md) devs are incapable of defining an unified import standard, this design pattern emerged where you just check every magic global one by one. Here's a demo where a Js library works on both the [browser](web-browser.md) and from [Node.js](node-js-split.md):
- [web-cheat/umd_my_lib.js](web-cheat/umd_my_lib.js): the library
- [web-cheat/umd.js](web-cheat/umd.js): [Node.js](node-js-split.md) user
- [web-cheat/umd.html](web-cheat/umd.html): [browser](web-browser.md) user
