# Quantum circuit description language

↑ **Parent:** [Quantum software](quantum-software.md)

These are a bit like the [Verilog](verilog.md) of [quantum computing](quantum-computing-split.md).

One would hope that they are not [Turing complete](turing-complete.md), this way they may serve as a way to pass on data in such a way that the receiver knows they will only be doing so much computation in advance to unpack the circuit. So it would be like [JSON](json.md) is for [JavaScript](javascript.md).
