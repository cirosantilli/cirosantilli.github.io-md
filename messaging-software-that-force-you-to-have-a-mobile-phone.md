# Messaging software that force you to have a mobile phone

↑ **Parent:** [Messaging software](messaging-software-split.md)

[https://lifehacker.com/how-to-use-signal-without-revealing-your-private-phone-1818996580](https://lifehacker.com/how-to-use-signal-without-revealing-your-private-phone-1818996580)
