# Computer science

↑ **Parent:** [Computer](computer-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Computer_science)

A branch of [mathematics](mathematics-split.md) that attempts to prove stuff about [computers](computer-split.md).

Unfortunately, all [software engineers](software-engineer.md) already know the answer to the useful theorems though (except perhaps notably for [cryptography](cryptography-split.md)), e.g. all programmers obviously know that iehter [P != NP](p-versus-np-problem.md) or that this is [unprovable or some other "for all practical purposes practice P != NP"](independence-mathematical-logic.md), even though they don't have proof.

And 99% of their time, software engineers are not dealing with mathematically formulatable problems anyways, which is sad.

The only useful "computer science" subset every programmer ever needs to know is:
- for arrays: [dynamic array](dynamic-array.md) vs [linked list](linked-list.md)
- for [associative array](associative-array.md): [binary search tree](binary-search-tree.md) vs [hash table](hash-table.md). See also [Heap vs Binary Search Tree (BST)](https://stackoverflow.com/questions/6147242/heap-vs-binary-search-tree-bst/29548834#29548834). No need to understand the algorithmic details of the hash function, the [NSA](national-security-agency.md) has already done that for you.
- don't use [Bubble sort](https://en.wikipedia.org/wiki/Bubble_sort) for sorting
- you can't parse HTML with regular expressions: [https://stackoverflow.com/questions/1732348/regex-match-open-tags-except-xhtml-self-contained-tags/1732454#1732454](https://stackoverflow.com/questions/1732348/regex-match-open-tags-except-xhtml-self-contained-tags/1732454#1732454) because of [formal language theory](formal-language-theory.md)

Funnily, due to the [formalization of mathematics](formalization-of-mathematics-split.md), [mathematics](mathematics-split.md) can be seen as a branch of computer science, just like computer science can be seen as a branch of Mathematics!
