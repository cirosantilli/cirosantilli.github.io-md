# Weapon grade Plutonium is cheaper than weapon grade Uranium

↑ **Parent:** [Uranium vs Plutonium](uranium-vs-plutonium.md)

Because you can generate [plutonium-239](plutonium-239.md) from [uranium-238](uranium-238.md) in a [breeder reactor](breeder-reactor.md), and then separate the [plutonium-239](plutonium-239.md) from the [Uranium](uranium.md) simply by using [chemistry](chemistry-split.md) methods because you've created an element with different valence electrons.

Isn't it somewhat funny that it is easier to purify a synthetic element than a naturally occurring one?
