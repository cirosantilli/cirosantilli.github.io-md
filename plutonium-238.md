# Plutonium-238

↑ **Parent:** [Plutonium isotope](plutonium-isotope.md)

Strong [alpha emitter](alpha-decay.md). Can be used as an [atomic battery](atomic-battery.md).

<a id="image-plutonium-238-oxide-pellet-glowing-under-its-own-heat"></a>
![](https://upload.wikimedia.org/wikipedia/commons/7/71/Plutonium_pellet.jpg)

**[Figure 20](#image-plutonium-238-oxide-pellet-glowing-under-its-own-heat). Plutonium-238-oxide pellet glowing under its own heat**. [Source](https://commons.wikimedia.org/wiki/File:Plutonium_pellet.jpg). Unlike for nuclear applications, we don't need the pure metal, so the oxide <sup>238</sup>PuO<sub>2</sub> is used instead as it is more chemically stable.
