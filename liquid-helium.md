# Liquid helium

↑ **Parent:** [Helium](helium.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Liquid_helium)

4 K. Enough for to make "low temperature [superconductors](superconductivity.md)" like regular metals superconducting, e.g. the [superconducting temperature of aluminum](superconducting-temperature-of-aluminum.md) if 1.2 K.

Contrast with [liquid nitrogen](liquid-nitrogen.md), which is much cheaper but only goes to 77K.
