# Doing physics means calculating a number

↑ **Parent:** [How to teach and learn physics](how-to-teach-and-learn-physics.md)  
🏷️ **Tags:** [Cirism](cirism-split.md)

In Physics, in order to test a theory, you must be able to extract a number from it.

It does not matter how, if it is exact, or numerical, or a message from [God](god.md): a number has to come out of the formulas in the end, and you have to compare it with the experimental data.

Many theoretical physicists seem to forget this in their lectures, see also: [Section "How to teach and learn physics"](how-to-teach-and-learn-physics.md).
