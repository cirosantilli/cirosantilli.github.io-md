# Exponentiation functional equation

↑ **Parent:** [Exponentiation](exponentiation.md)  
🏷️ **Tags:** [Functional equation](functional-equation.md)

We define this as the [functional equation](functional-equation.md):

$$
f(x, y) = f(x)f(y)
$$

It is a bit like [cauchy's functional equation](cauchy-s-functional-equation.md) but with [multiplication](multiplication.md) instead of [addition](addition.md).
