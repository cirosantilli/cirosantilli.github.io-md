# Projects must aim for novelty

↑ **Parent:** [Exams and homework are useless, only projects matter](exams-and-homework-are-useless-only-projects-matter.md)

<a id="_140"></a>
The projects you do must always aim to achieving some [novel result](../novel-result.md).

<a id="_141"></a>
You don't have to necessarily reach it. But you must aim for it.

<a id="_142"></a>
Novel result can be taken broadly.

<a id="_143"></a>
E.g., a new tutorial that explains something in a way never done before is novel.

<a id="_144"></a>
But there must be something to your project that has never been done before.

<a id="_145"></a>
You can start by reproducing other's work.
