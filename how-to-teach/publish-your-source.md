# Publish your source

↑ **Parent:** [How to teach](../how-to-teach-split.md)

<a id="_87"></a>
For example, if you write LaTeX files for you PDFs, give both PDFs and the LaTeX.

<a id="_88"></a>
This allows other people to:<a id="_89"></a>

<a id="_90"></a>
- modify and reuse your material
<a id="_91"></a>
- <a id="_92"></a>
  make improvement suggestions that you can accept by clicking a button

  <a id="_93"></a>
  The perfect way to do this is to use [GitHub pull requests](https://help.github.com/articles/about-pull-requests/)
