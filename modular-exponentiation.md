# Modular exponentiation

↑ **Parent:** [Modular arithmetic](modular-arithmetic.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Modular_exponentiation)

Can be calculated efficiently with the [Extended Euclidean algorithm](extended-euclidean-algorithm.md).

The [beauty](the-beauty-of-mathematics.md) of this algorithm is that because [exponentiation grows really fast](exponentiation-grows-really-fast.md), there is no hope that we can ever learn all the digits of an exponential, as there is simply not enough time or memory for that. Therefore, a natural sub-question is if we can know some part of that number, and knowing the smallest digits is the most natural version of that question.
