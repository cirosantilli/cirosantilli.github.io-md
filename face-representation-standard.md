# Face representation standard

↑ **Parent:** [Facial recognition system](facial-recognition-system.md)

Is there nothing standardized besides just raw images?

E.g. [https://www.nist.gov/system/files/documents/2021/02/25/ansi-nist_2007_griffin-face-std-m1.pdf](https://www.nist.gov/system/files/documents/2021/02/25/ansi-nist_2007_griffin-face-std-m1.pdf) from 2005 by [NIST](national-institute-of-standards-and-technology.md) says:

> Specify face images because there is no agreement on a standard face recognition template - Unlike [finger minutiae](fingerprint-minutiae.md) ...

so comparing it to [fingerprint file formats](fingerprint-file-format.md) such as [ISO 19794-2](iso-19794-2.md). Sad!
