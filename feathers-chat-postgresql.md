# feathers-chat PostgreSQL

↑ **Parent:** [feathersjs/feathers-chat](feathersjs-feathers-chat.md)

The default feathers-chat app runs on NeDB (local filesystem [JSON](json.md) database).

[Ciro Santilli](ciro-santilli-split.md) managed to port it to [Sequelize](sequelize-split.md) for [PostgreSQL](postgresql.md) as shown at: [https://github.com/cirosantilli/feathers-chat/tree/sequelize-pg](https://github.com/cirosantilli/feathers-chat/tree/sequelize-pg)
