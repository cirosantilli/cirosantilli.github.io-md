# Inkscape

↑ **Parent:** [Image editor](image-editor.md)  
🏷️ **Tags:** [Mathematics illustration software](mathematics-illustration-software.md), [Software with bad user interface](software-with-bad-user-interface.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Inkscape)

Inkscape is a a good software for editing/creating [SVG](scalable-vector-graphics.md) files.

Its functionality is fundamental for as a [software for drawing geometry diagrams](mathematics-illustration-software.md), as it is a good middle ground between algorithmic generation, and [raster graphics](raster-graphics.md).

At 1.0.2, its [UI](user-interface.md) is a bit terrible:
- the way the menus open on the right with title below the window...
- several defaults are atrocious, e.g. export drawing rather than page

And it crashes from time to time on [Ubuntu](ubuntu.md) 21.04. And it has some glaring bugs, e.g.:
- [https://gitlab.com/inkscape/inbox/-/issues/5794](https://gitlab.com/inkscape/inbox/-/issues/5794)

But still, it is a very good initiative.
