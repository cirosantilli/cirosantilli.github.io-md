# Raspberry Pi Pico W MicroPython example

↑ **Parent:** [Program Raspberry Pi Pico W with MicroPython](program-raspberry-pi-pico-w-with-micropython.md)

An upstream repo at: [https://github.com/raspberrypi/pico-micropython-examples](https://github.com/raspberrypi/pico-micropython-examples)

Some generic Micropython examples most of which work on this board can be found at: [Section "MicroPython example"](micropython-example.md).

Pico W specific examples are under: [rpi-pico-w/upython](rpi-pico-w/upython).

The examples can be run as described at [Program Raspberry Pi Pico W with MicroPython](program-raspberry-pi-pico-w-with-micropython.md).

- [rpi-pico-w/upython/led_on.py](rpi-pico-w/upython/led_on.py): turn on-board LED on and leave it on forever. Useful to quickly check that you are still able to update the firmware.
- [rpi-pico-w/upython/led_off.py](rpi-pico-w/upython/led_off.py): turn on-board LED off and leave it off forever
- [rpi-pico-w/upython/pwm.py](rpi-pico-w/upython/pwm.py): [pulse width modulation](pulse-width-modulation.md). Using the same circuit as the [rpi-pico-w/upython/blink_gpio.py](_file/rpi-pico-w/upython/blink_gpio.py.md), you will now see the external LED go from dark to bright continuously  and then back
