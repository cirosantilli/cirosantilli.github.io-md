# Photon polarization

↑ **Parent:** [Photonics](photonics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Photon_polarization)

The knowledge that light is polarized precedes the knowledge of the existence of the photon, see [polarization of light](polarization-of-light.md) for the classical point of view.

The polarization state and how it can be decomposed into different modes can be well visualized with the [Poincaré sphere](poincare-sphere.md).

One key idea about photon polarization is that it carries [angular momentum](angular-momentum.md). Therefore, when an electron changes orbitals in the [Schrödinger equation solution for the hydrogen atom](schrodinger-equation-solution-for-the-hydrogen-atom.md), the angular momentum (as well as energy) change is carried out by the polarization of the [photon](photon-split.md)!
