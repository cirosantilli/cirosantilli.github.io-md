# Conjecture reduction to a halting problem

↑ **Parent:** [Automated theorem proving by halting problem reduction](automated-theorem-proving-by-halting-problem-reduction.md)

[https://bbchallenge.org/story#what-is-known-about-bb](https://bbchallenge.org/story#what-is-known-about-bb) lists some (all?) cool examples, 
- BB(15): [Erdős' conjecture on powers of 2](erdos-conjecture-on-powers-of-2.md), which has some relation to [Collatz conjecture](collatz-conjecture.md)
- BB(27): [Goldbach's conjecture](goldbach-s-conjecture.md)
- BB(744): [Riemann hypothesis](riemann-hypothesis.md)
- BB(748): [independent](independence-mathematical-logic.md) from the [Zermelo-Fraenkel axioms](zermelo-fraenkel-axioms.md)
- BB(7910): [independent](independence-mathematical-logic.md) from the [ZFC](zermelo-fraenkel-axioms-with-the-axiom-of-choice.md)

[https://wiki.bbchallenge.org/wiki/Cryptids](https://wiki.bbchallenge.org/wiki/Cryptids) contains a larger list. In June 2024 it was discovered that [BB(6) is hard](bb-6-is-hard.md).
