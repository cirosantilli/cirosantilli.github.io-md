# PSE

↑ **Parent:** [x86 Paging Tutorial](../x86-paging-split.md)

<a id="_267"></a>
Page size extension.

<a id="_268"></a>
Allows for pages to be 4M (or 2M if PAE is on) in length instead of 4K.

<a id="_269"></a>
PSE is turned on and off via the `PSE` bit of `cr4`.
