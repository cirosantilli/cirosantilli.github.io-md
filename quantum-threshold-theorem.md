# Quantum threshold theorem

↑ **Parent:** [Quantum error correction](quantum-error-correction.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quantum_threshold_theorem)

This theorem roughly states that states that for every [quantum algorithm](quantum-algorithm.md), once we reach a certain level of physical error rate small enough (where small enough is algorithm dependant), then we can _perfectly_ error correct.

This algorithm provides the conceptual division between [noisy intermediate-scale quantum era](noisy-intermediate-scale-quantum-era.md) and post-NISQ.
