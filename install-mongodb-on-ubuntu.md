# Install MongoDB on Ubuntu

↑ **Parent:** [MongoDB](mongodb.md)

Tested as of Ubuntu 20.04, there is no Mongo package available by default due to their change to [Server Side Public License](server-side-public-license.md), which Debian opposed. Therefore, you have to add their custom PPA as mentioned at: [https://docs.mongodb.com/manual/tutorial/install-mongodb-on-ubuntu/](https://docs.mongodb.com/manual/tutorial/install-mongodb-on-ubuntu/)
