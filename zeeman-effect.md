# Zeeman effect

↑ **Parent:** [Spectral line](spectral-line.md)  
🏷️ **Tags:** [1902 Nobel Prize in Physics](1902-nobel-prize-in-physics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Zeeman_effect)

Split in the [spectral line](spectral-line.md) when a [magnetic field](magnetic-field.md) is applied.

Non-anomalous: number of splits matches predictions of the [Schrödinger equation](schrodinger-equation.md) about the number of possible states with a given angular momentum. TODO does it make numerical predictions?

[Anomalous](anomalous-zeeman-effect.md): evidence of [spin](spin-physics.md).

[http://www.pas.rochester.edu/~blackman/ast104/zeeman-split.html](http://www.pas.rochester.edu/~blackman/ast104/zeeman-split.html) contains the hello world that everyone should know: 2p splits into 3 energy levels, so you see 3 spectral lines from 1s to 2p rather than just one.

p splits into 3, d into 5, f into 7 and so on, i.e. one for each possible [azimuthal quantum number](azimuthal-quantum-number.md).

It also mentions that polarization effects become visible from this: each line is polarized in a different way. TODO more details as in an experiment to observe this.

Well explained at: [Video 19. "Quantum Mechanics 7a - Angular Momentum I by ViaScience (2013)"](angular-momentum-operator.md#video-quantum-mechanics-7a-angular-momentum-i-by-viascience-2013).
