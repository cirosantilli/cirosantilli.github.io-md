# EPUB

↑ **Parent:** [E-book file format](e-book-file-format.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/EPUB)

This is a good thing. It basically contains an entire [website](website-split.md), with [HTML](html.md) and assets inside a single [ZIP](zip-file-format.md), and a little bit of metadata.

It is incomprehensible why [browsers](web-browser.md) don't just implement it as they already have all the web part, and also [ZIP](zip-file-format.md) stuff:
- [https://www.quora.com/What-is-the-reason-that-browsers-cannot-open-epub-files-without-extensions](https://www.quora.com/What-is-the-reason-that-browsers-cannot-open-epub-files-without-extensions) on [Quora](quora.md)

The situation is so sad. [Ubuntu](ubuntu.md) 21.04 doesn't come with a reader installed by default:
- [https://askubuntu.com/questions/14378/what-software-can-i-use-to-view-epub-documents](https://askubuntu.com/questions/14378/what-software-can-i-use-to-view-epub-documents)
