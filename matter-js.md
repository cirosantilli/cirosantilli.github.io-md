To run the demos locally, tested on [Ubuntu 22.10](ubuntu-22-10.md):
```
git clone https://github.com/liabru/matter-js
cd matter-js
git checkout 0.19.0
npm install
npm run dev
```
and this opens up the demos on the browser.
