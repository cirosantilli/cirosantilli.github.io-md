# [Project Euler](project-euler-split.md) [Lean](lean-proof-assistant.md) solutions

↑ **Parent:** [Project Euler solutions in X](project-euler-solutions-in-x.md)

Using [Lean](lean-proof-assistant.md) or other programmable [proof assistants](proof-assistant.md) to solve [Project Euler](project-euler-split.md) is the inevitable collision of two [autisms](autism.md). In particular, using [Lean](lean-proof-assistant.md) to prove that you have the correct solution, just making a Lean program that prints out the correct solution is likely now trivial as of 2025 by asking an [LLM](large-language-model.md) to port a [Python](python-programming-language.md) solution to the new language.

Some efforts:
- [https://github.com/mfornet/project-euler-lean](https://github.com/mfornet/project-euler-lean) Attempts proofs, but only did [Project Euler problem 1](project-euler-problem-1.md) :-)
- [https://github.com/pcpthm/pe](https://github.com/pcpthm/pe) solved the first 50, but as stated on the README itself, no proofs, so boring
- [https://unreasonableeffectiveness.com/learning-lean-4-as-a-programming-language-project-euler/](https://unreasonableeffectiveness.com/learning-lean-4-as-a-programming-language-project-euler/) solves 4, but no proofs
