# Kibble balance

↑ **Parent:** [Kilogram](kilogram.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Kibble_balance)

The [Kibble balance](kibble-balance.md) is so precise and reproducible that it was responsible for the [2019 redefinition of the Kilogram](2019-redefinition-of-the-kilogram.md).

<a id="image-nist-4-kibble-balance"></a>
<img src="https://upload.wikimedia.org/wikipedia/commons/f/f8/NIST-4_Kibble_balance.jpg" alt="" height="800">

**[Figure 2](#image-nist-4-kibble-balance). NIST-4 Kibble balance**. [Source](https://commons.wikimedia.org/wiki/File:NIST-4_Kibble_balance.jpg).

It relies rely on not one, but three macroscopic [quantum mechanical](quantum-mechanics-split.md) effects:
- [atomic spectra](emission-spectrum.md): basis for the [caesium standard](caesium-standard.md) which produces precise time and frequency
- [Josephson effect](josephson-effect.md): basis for the [Josephson voltage standard](josephson-voltage-standard.md), which produces precise [voltage](voltage.md)
- [quantum Hall effect](quantum-hall-effect.md): basis for the [quantum Hall effect](quantum-hall-effect.md), which produces precise [electrical resistance](electrical-resistance.md)
How cool is that! As usual, the advantage of those effects is that they are discrete, and have very fixed values that don't depend either:
- on the physical dimensions of any apparatus (otherwise fabrication precision would be an issue)
- small variations of temperature, magnetic field and so on
One downside of using some [quantum mechanical](quantum-mechanics-split.md) effects is that you have to cool everything down to 5K. But that's OK, we've got [liquid helium](liquid-helium.md)!

The operating principle is something along:
- generate a precise frequency with a [signal generator](signal-generator.md), ultimately calibrated by the [Caesium standard](caesium-standard.md)
- use that precise frequency to generate a precise [voltage](voltage.md) with a [Josephson voltage standard](josephson-voltage-standard.md)
- convert that precise voltage into a precise [electric current](electric-current.md) by using the [quantum Hall effect](quantum-hall-effect.md), which produces a very precise [electrical resistance](electrical-resistance.md)
- use that precise current to generate a precise force on the object your weighing, pushing it against [gravity](gravity.md)
- then you precisely measure both:
  - local [gravity](gravity.md) with a [gravimeter](gravimeter.md)
  - the displacement acceleration of the object with a laser setup
Then, based on all this, you can determine how much the object weights.
