# Wireshark

↑ **Parent:** [Computer network software](computer-network-software.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Wireshark)

Amazing tool that captures packets and disassembles them. Allows you to click an interactive tree that represents [Ethernet](ethernet.md), [TCP/IP](tcp-ip.md) and application layer like [HTTP](http.md).

Start capture immediately from CLI, capture packets to/from 192.168.1.102:
```
sudo wireshark -f 'host 192.168.1.102' -k
```
