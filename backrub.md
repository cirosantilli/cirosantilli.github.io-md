# BackRub

↑ **Parent:** [History of Google](history-of-google.md)

This was the original name of [Google Search](google-search.md).

One wonders if this name has some influence from the [LGBT culture in San Francisco](lgbt-culture-in-san-francisco.md)! The [sexual innuendo](sexual-innuendo.md) is palpable.

"Back" is of course a reference to "[backlinks](https://ourbigbook.com/go/topic/backlinks)", since [Google Search](google-search.md) relies on incoming links (AKA backlinks) to a webpage to determine its importance.
