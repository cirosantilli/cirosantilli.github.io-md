# Onion service

↑ **Parent:** [Tor (anonymity network)](tor-anonymity-network.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/en.wikipedia.org/wiki/Tor_(network)#Onion_services)

This is a way to host a server that actually hide the [IP](ip-address.md) of the server from the client, just like [Tor](tor-anonymity-network.md) hides the [IP](ip-address.md) of the client from the server. Amazing tecnology!

This is why it enables hosting [illegal](law-split.md) things like the [Silk Road](silk-road-marketplace.md): [law enforcement](law-enforcement.md) is not able find where the server is hosted, and take it down or identify the owner.
