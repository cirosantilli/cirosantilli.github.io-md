# Dirichlet boundary condition

↑ **Parent:** [Boundary condition](boundary-condition.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Dirichlet_boundary_condition)

Specifies fixed values.

Can be used for [elliptic partial differential equations](elliptic-partial-differential-equation.md) and [parabolic partial differential equations](parabolic-partial-differential-equation.md).
