# re-arc

↑ **Parent:** [ARC-AGI problem generator](arc-agi-problem-generator.md)

[https://github.com/michaelhodel/re-arc](https://github.com/michaelhodel/re-arc)

By the author of [ARC-DSL](arc-dsl.md).

README says:

> This repository presents code to procedurally generate examples for the ARC training tasks. For each of the 400 tasks, an example generator is provided.

[https://arxiv.org/html/2404.07353v1](https://arxiv.org/html/2404.07353v1) says:

> Each generator is a standalone Python function merely making use of the [DSL](arc-dsl.md) and functions from the random module from the standard library. The median generator consists of 40 lines of code and uses 22 DSL primitive calls and 10 calls to the random module.

Cool!
