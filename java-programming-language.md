Java is good.

Its boilerplate requirement is a pain, but the design is otherwise very clean.

But its ecosystem sucks.

The development process is rather closed, the issue tracker obscure.

And above all, [Google LLC v. Oracle America, Inc.](google-llc-v-oracle-america-inc.md) killed everybody's trust in it once and for all. Thanks [Oracle](oracle-corporation.md).
