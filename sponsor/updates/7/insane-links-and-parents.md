# Insane links and parents

↑ **Parent:** [Advances](advances.md)

You can now write:
```
<Blue cats> are nice.

= Blue cat

= Big blue cat
{parent=Blue cat}
```
in lieu of the old:
```
\x[blue-cat]{c}{p} are nice.

= Blue cat

= Big blue cat
{parent=blue-cat}
```
