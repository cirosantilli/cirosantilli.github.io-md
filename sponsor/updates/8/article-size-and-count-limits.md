# Article size and count limits

↑ **Parent:** [Advances](advances.md)

<a id="_18"></a>
Limited the number of articles, and the size of article bodies. This, together with the reCAPTCHA setup from [Email verification and reCAPTCHA signup protection](../7/email-verification-and-recaptcha-signup-protection.md) should prevent the most basic types of [denial-of-service](../../../denial-of-service-attack.md) attacks by filling up our database.

<a id="_19"></a>
The limits can be increased by admin users from the web UI, and will be done generously when it is evident that it is not a [DoS attack](../../../denial-of-service-attack.md). Admin users are also a recently added feature.
