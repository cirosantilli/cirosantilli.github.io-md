# Completely rebrand Cirodown to OurBigBook

↑ **Parent:** [Advances](advances.md)

<a id="_18"></a>
The name cirodown should not appear anywhere now, except with very few exceptions, e.g.:<a id="_19"></a>

<a id="_20"></a>
- [https://github.com/cirosantilli/cirodown](https://github.com/cirosantilli/cirodown) to [https://github.com/ourbigbook/ourbigbook](https://github.com/ourbigbook/ourbigbook)
<a id="_21"></a>
- file extension from `.ciro` to `.bigb`
<a id="_22"></a>
- the Node.js NPM package was renamed from `cirodown` to `ourbibook`.
<a id="_23"></a>
- all in-code instances

<a id="_24"></a>
I have also squatted `OurBigBook` on all major social media handles for near future usage, e.g.: [https://twitter.com/ourbigbook](https://twitter.com/ourbigbook) and so on.

<a id="_25"></a>
I was going to do this sooner or later, it was inevitable, but the timing was partly triggered due to noticing that English speakers (and likely many other nationalities) are not able to easily read/hear/pronounce "Ciro".
