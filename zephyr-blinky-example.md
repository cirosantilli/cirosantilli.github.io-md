# Zephyr blinky example

↑ **Parent:** [Zephyr official example](zephyr-official-example.md)

Blinks the on-board LED if the board has one.

Does not work on:
- [Micro Bit](micro-bit.md): build fails
- [Raspberry Pi Pico W](raspberry-pi-pico-w.md): build works but does nothing because the LED is connected differently
