# Elliptic-curve Diffie-Hellman

↑ **Parent:** [Elliptic curve cryptography](elliptic-curve-cryptography.md)  
🏷️ **Tags:** [Diffie-Hellman key exchange](diffie-hellman-key-exchange.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Elliptic-curve_Diffie-Hellman)

The algorithm is completely analogous to [Diffie-Hellman key exchange](diffie-hellman-key-exchange.md) in that you efficiently raise a number to a power $n$ times and send the result over while keeping $n$ as private key.

The only difference is that a different group is used: instead of using the [cyclic group](cyclic-group.md), we use the [elliptic curve group](elliptic-curve-group.md) of an [elliptic curve over a finite field](elliptic-curve-over-a-finite-field.md).
