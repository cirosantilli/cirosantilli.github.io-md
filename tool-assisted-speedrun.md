# Tool-assisted speedrun

↑ **Parent:** [Speedrun](speedrun.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tool-assisted_speedrun)

To some extent, the ultimate achievement of a TAS is to achieve [arbitrary code execution](arbitrary-code-execution.md) (ACE) on a game, although this has been becoming rarer and rarer in newer consoles. The [Nintendo 64](nintendo-64.md) is the current interesting ACE discovery frontier as of 2020.

Post ACE, you then get into more subtle categories which tend to be more geometric clipping through wall glitches, but those can still be fun.
