# Stack Exchange

↑ **Parent:** [Alternatives](alternatives.md)

<a id="_81"></a>
[Stack Exchange](stack-exchange.md) solves to a good extent the use  cases:<a id="_82"></a>

<a id="_83"></a>
- I have a very specific question, type it on [Google](../google-split.md), find top answers
<a id="_84"></a>
- I have an answer, and I put it here because it has a much greater chance of being found due to the larger [PageRank](../pagerank.md) than my [personal web page](../personal-web-page.md) will ever have
points of view. It is a big open question if we can actually substantially improve it.

<a id="_85"></a>
Major shortcoming are mentioned at [idiotic Stack Overflow policies](../bad-stack-overflow-policies.md):<a id="_86"></a>

<a id="_87"></a>
- <a id="_88"></a>
  Scope restrictions can lead to a lot of content deletion: [closing questions as off-topic](../closing-questions-as-off-topic.md)<a id="_89"></a>

  <a id="_90"></a>
  - [closing questions as off-topic](../closing-questions-as-off-topic.md)
  <a id="_91"></a>
  - [Stack Overflow content deletion](../stack-overflow-content-deletion.md)
  <a id="_92"></a>
  - [Stack Overflow link-only answer policy](../stack-overflow-link-only-answer-policy.md)
  <a id="_93"></a>
  - [Stack Overflow no duplicate answers policy](../stack-overflow-no-duplicate-answers-policy.md)
  This greatly discourages new users, who might still have added value to the project.

  <a id="_94"></a>
  On our website, anyone can post anything that is legal in a given country. No one can ever delete your content if it is legal, no matter their reputation.
<a id="_95"></a>
- Although you can answer your own question, there's no way to write an organized multi-page book with Stack Exchange due to shortcomings such as no table of contents, 30k max chars on answer, huge risk of deletion due to "too broad"
<a id="_96"></a>
- Absolutely no algorithmic attempt to overcome the fastest gun in the West problem (early answers have huge advantage over newer ones): [https://meta.stackoverflow.com/questions/404535/closing-an-old-upvoted-question-as-duplicate-of-new-unvoted-questions/404567#404567](https://meta.stackoverflow.com/questions/404535/closing-an-old-upvoted-question-as-duplicate-of-new-unvoted-questions/404567#404567)
<a id="_97"></a>
- Native reputation system:<a id="_98"></a>

  <a id="_99"></a>
  - if the living ultimate [God](../god.md) of `C++` upvotes you, you get `10` reputation
  <a id="_100"></a>
  - if the first-day newb of `Java` upvotes you, you also get `10` reputation
<a id="_101"></a>
- Randomly split between sites like Stack Overflow vs Super User, with separate user reputations, but huge overlaps, and many questions that appears as dupes on both and never get merged.
<a id="_102"></a>
- Possible edit wars, just like [Wikipedia](wikipedia.md), but these are much less common since content ownership is much clearer than in Wikipedia however
