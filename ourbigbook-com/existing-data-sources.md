Some possible/not possible sources that could be used to manually bootstrap content:<a id="_168"></a>

<a id="_169"></a>
- [LibreTexts](../libretexts.md). Good project. "Teacher-only-content" unfortunately as usual. But besides that fundamental flaw, they do exactly what we want to do in a sense.
<a id="_170"></a>
- [OpenStax](../openstax.md): [CC BY](../cc-by.md). This could be a great entry point, as they already have some university integration going on, and might be interested in this project.
<a id="_171"></a>
- [https://physics.stackexchange.com/questions/6157/list-of-freely-available-physics-books](https://physics.stackexchange.com/questions/6157/list-of-freely-available-physics-books) "List of freely available physics books" explicitly asks for:<a id="_172"></a>
  > a list of physics books with open-source licenses, like Creative Commons, GPL

  but the thread [was locked](../closing-questions-as-off-topic.md), and basically none of the sources in the answers have free licenses, nor do they note it. It just seems that the [physicists](../physicist-split.md) don't know what a [free license](../free-license.md) is.
<a id="_173"></a>
- [MIT OpenCourseWare](../mit-opencourseware.md): [CC BY-NC-SA](../cc-by-nc-sa.md), so not really usable
<a id="_174"></a>
- [https://github.com/certik/theoretical-physics](https://github.com/certik/theoretical-physics): [MIT License](../mit-license.md). [Workable](https://opensource.stackexchange.com/questions/324/are-permissive-licenses-mit-bsd-zlib-compatible-with-cc-by) but wonky.
<a id="_175"></a>
- [https://subwiki.org/](https://subwiki.org/): [wiki](../wiki.md) with some upper graduate [math](../mathematics-split.md) subjects presumably by this [Indian](../india.md) dude: [https://www.linkedin.com/in/vipul-naik-0ab1898/](https://www.linkedin.com/in/vipul-naik-0ab1898/). Description on his homepage: [https://vipulnaik.com/subwiki/](https://vipulnaik.com/subwiki/). He's also got other interesting but not so relevant projects:<a id="_176"></a>

  <a id="_177"></a>
  - pro freer immigration laws: [https://vipulnaik.com/openborders/](https://vipulnaik.com/openborders/)
  <a id="_178"></a>
  - [https://vipulnaik.com/cognito-mentoring/](https://vipulnaik.com/cognito-mentoring/) free mentoring project for interested students

  He's also into [Stack Overflow](../stack-overflow-split.md), [Quora](../quora.md) and [Wikipedia](wikipedia.md) editing. That's a cool dude. He's into in [LessWrong](../lesswrong.md) it seems.
<a id="_179"></a>
- massive [mathematics](../mathematics-split.md) books<a id="_180"></a>

  <a id="_181"></a>
  - [Infinite Napkin](../infinite-napkin.md).[CC BY-SA](../cc-by-sa.md) [mathematics](../mathematics-split.md) infinite book: [https://github.com/vEnhance/napkin/issues/77](https://github.com/vEnhance/napkin/issues/77). Very similar type of content to what we want in this project!
  <a id="_182"></a>
  - [Stacks Project](../stacks-project.md)
