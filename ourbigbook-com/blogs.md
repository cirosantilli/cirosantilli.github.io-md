# Blogs

↑ **Parent:** [Alternatives](alternatives.md)

<a id="_106"></a>
Where [blog](../blog.md) is taken in a wide sense, including e.g. [Medium](../medium-website.md), [WordPress](../wordpress.md), [Facebook](../facebook.md), [Twitter](../twitter.md), etc., etc.

<a id="_107"></a>
The main shortcoming of blogs is the lack of topic convergence across blogs. Each blog is a moderated castle. So who is the best user for a given topic, or the best content for a given tag, across the entire website?

<a id="_108"></a>
The only reasonable free material we have for advanced subjects nowadays are [university lecture notes](university-lecture-notes.md).

<a id="_109"></a>
While some of those are awesome, when writing a large content, no one can keep quality high across all sections, there will always be knowledge that you don't have which is enlightening. And [Googlers](../google-split.md) are more often than not interested only in specific sections of your content.

<a id="_110"></a>
Our website aims to make smaller subjects vertically curated across horizontal single author tutorials.

<a id="_111"></a>
```
MIT calculus course             UCLA calculus course

* Calculus                <---> * Calculus
  * Limit                 <--->   * Limit
    * Limit of a function
    * Limit of a series   <--->     * Limit of a series
  * Derivative            <--->   * Derivative
                                    * L'Hôpital's rule
  * Integral              <--->   * Integral
```
