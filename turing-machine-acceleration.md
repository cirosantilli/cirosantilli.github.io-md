# Turing machine acceleration

↑ **Parent:** [Specific values of the Busy beaver function](specific-values-of-the-busy-beaver-function.md)

[Turing machine acceleration](turing-machine-acceleration.md) refers to using high level understanding of specific properties of specific Turing machines to be able to simulate them much fatser than naively running the simulation as usual.

Acceleration allows one to use simulation to find infinite loops that might be very long, and would not be otherwise spotted without acceleration.

This is for example the case of [https://www.sligocki.com/2023/03/13/skelet-1-infinite.html](https://www.sligocki.com/2023/03/13/skelet-1-infinite.html) proof of [Skelet machine \#1](skelet-machine-1.md).
