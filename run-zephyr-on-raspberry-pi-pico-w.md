# Run Zephyr on [Raspberry Pi Pico W](raspberry-pi-pico-w.md)

↑ **Parent:** [Run Zephyr on Raspberry Pi Pico](run-zephyr-on-raspberry-pi-pico.md)

The Zephir [LED blinker](led-blinker.md) example does not work on the [Raspberry Pi Pico W](raspberry-pi-pico-w.md) because the on-board LED is wired differently. But the hello world works and with:
```
screen /dev/ttyUSB0 115200
```
host shows:
```
*** Booting Zephyr OS build v4.2.0-491-g47b07e5a09ef ***
Hello World! rpi_pico/rp2040
```
Nice!
