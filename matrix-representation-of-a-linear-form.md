# Matrix representation of a linear form

↑ **Parent:** [Linear form](linear-form.md)

For the typical case of a linear form over [$\R^n$](real-coordinate-space.md), the form can be seen just as a row vector with n elements, the full form being specified by the value of each of the [basis vectors](basis-linear-algebra.md).
