# Sinusoidal

↑ **Parent:** [Sine and cossine](sine-and-cossine.md)  
🏷️ **Tags:** [Periodic function](periodic-function.md)

A function that is either a [sine](sine.md) or [cosine](cosine.md), i.e. we don't know or care where the origin is exactly.

This is particularly relevant in [electronics](electronics-split.md), where the [oscilloscope](oscilloscope.md)'s time origin is set to match the wave.
