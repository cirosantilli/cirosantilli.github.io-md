# Amazon custom silicon

↑ **Parent:** [Amazon infrastructure](amazon-infrastructure.md)

Like [Google custom silicon](google-custom-silicon.md), [Amazon](amazon-split.md) server operations are so large that with the slowdown of [Moore's law](moore-s-law.md), it started being worth it for them to develop custom in-house silicon to serve as a competitive advantage, not to be sold for external companies. Can you imagine the scale required to justify silicon development investment that is not sold externally!
