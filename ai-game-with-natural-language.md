# AI game with natural language

↑ **Parent:** [AI game](ai-game.md)

We define this category as AI games in which agents are able to produce or consume [natural language](natural-language.md).

It dawned on [Ciro Santilli](ciro-santilli-split.md) that it would be very difficult to classify an agent as an [AGI](artificial-general-intelligence.md) if tthat agent can't speak to take orders, read existing human generated documentation, explain what it is doing, or ask for clarification.
