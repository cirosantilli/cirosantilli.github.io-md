# Atomicity (database systems)

↑ **Parent:** [ACID (database)](acid-database.md)

This means that e.g. if you do an `UPDATE` query on multiple rows, and power goes out half way, either all update, or none update.

This is different from [isolation](isolation-database-systems.md), which considers instead what can or cannot happen when multiple queries are running in parallel.
