# Tcl

↑ **Parent:** [List of programming languages](list-of-programming-languages.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Tcl)

One of the first big [interpreted programming languages](interpreted-programming-language.md) to go a bit further than [Bash](bash-unix-shell.md)' word replacement insanity.

To the modern viewer, it feels like a middle ground between [Bash](bash-unix-shell.md) and [Python](python-programming-language.md).

It was completely insane however, and it just died: [Python](python-programming-language.md) is much saner, and [Bash](bash-unix-shell.md), although totally insane still [golfs](code-golf.md) better, especially on the file manipulation context.
