# DNA detection

↑ **Parent:** [DNA](dna-split.md)

DNA detection means determining if a specific DNA sequence is present in a sample.

This can be used to detect if a given species of microorganism is present in a sample, and is therefore a widely used diagnostics technique to see if someone is infected with a virus.

You could of course do full [DNA Sequencing](dna-sequencing.md) to see everything that is there, but since it is as a more generic procedure, sequencing is more expensive and slow.

The alternative is to use a [DNA amplification](dna-amplification.md) technique.
