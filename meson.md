# Meson

↑ **Parent:** [Hadron](hadron.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Meson)

[composite particle](composite-particle.md) made up of an even number of [elementary particles](elementary-particle.md), most commonly one particle and one anti-particle.

This can be contrasted with [mesons](meson.md), which have an odd number of elementary particles, as mentioned at [baryon vs meson vs lepton](baryon-vs-meson-vs-lepton.md).
