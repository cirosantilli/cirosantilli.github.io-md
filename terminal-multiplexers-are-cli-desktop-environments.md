# Terminal multiplexers are CLI desktop environments

↑ **Parent:** [Terminal multiplexer](terminal-multiplexer.md)

If we didn't have [GUIs](graphical-user-interface.md), [terminal multiplexers](terminal-multiplexer.md) would be our [desktop environments](desktop-environment.md). E.g. they handle stuff like:
- window switching
- copy pasting across windows
- screen locking
- clock on the status bar (same one that holds tabs)
It is a thing of beauty.
