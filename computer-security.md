As mentioned at [Section "Computer security researcher"](computer-security-researcher.md), [Ciro Santilli](ciro-santilli-split.md) really tends to like people from this area.

Also, the type of programming Ciro used to do, [systems programming](systems-programming-split.md), is particularly useful to security researchers, e.g. [Linux Kernel Module Cheat](linux-kernel-module-cheat-split.md).

The reason he does not go into this is that Ciro would rather fight against the more eternal [laws of physics](law-of-physics.md) rather than with some typo some dude at [Apple](apple-inc-split.md) did last week and which will be patched in a month.
