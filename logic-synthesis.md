# Logic synthesis

↑ **Parent:** [Electronic design automation phase](electronic-design-automation-phase.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Logic_synthesis)

Step of [electronic design automation](electronic-design-automation.md) that maps the [register transfer level](register-transfer-level.md) input (e.g. [Verilog](verilog.md)) to a [standard cell library](standard-cell-library.md).

The output of this step is another [Verilog](verilog.md) file, but one that exclusively uses interlinked cell library components.
