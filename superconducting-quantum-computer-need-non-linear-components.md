# Superconducting quantum computer need non-linear components

↑ **Parent:** [Superconducting quantum computing](superconducting-quantum-computing.md)

Non-linearity is needed otherwise the input energy would just make the state go to higher and higher energy levels, e.g. from 1 to 2. But we only want to use levels 0 and 1.

The way this is modelled in by starting from a pure [LC circuit](lc-circuit.md), which is an harmonic oscillator, see also [quantum LC circuit](quantum-lc-circuit.md), and then replacing the linear [inductor](inductor.md) with a [SQUID device](squid-device.md), e.g. mentioned at: [https://youtu.be/eZJjQGu85Ps?t=1655](https://youtu.be/eZJjQGu85Ps?t=1655) [Video 10. "Superconducting Qubits I Part 1 by Zlatko Minev (2020)"](superconducting-quantum-computing.md#video-superconducting-qubits-i-part-1-by-zlatko-minev-2020).
