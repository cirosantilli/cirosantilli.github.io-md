OK, now we're talking, two liner and you get a window showing [bounding box](bounding-box.md) object detection from your [webcam](webcam.md) feed!
```
python -m pip install -U yolov5==7.0.9
yolov5 detect --source 0
```
The accuracy is crap for anything but people. But still. Well done. Tested on [Ubuntu 22.10](ubuntu-22-10.md), [P51](ciro-santilli-s-hardware/lenovo-thinkpad-p51-2017.md).
