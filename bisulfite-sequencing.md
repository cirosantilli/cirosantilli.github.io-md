# Bisulfite sequencing

↑ **Parent:** [DNA methylation](dna-methylation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bisulfite_sequencing)

The main way to sequence [DNA methylation](dna-methylation.md). Converts methylated [cytosine](cytosine.md) to [uracil](uracil.md), and then we can sequence those.
