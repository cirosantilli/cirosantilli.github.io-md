# Algebraic number field

↑ **Parent:** [Algebraic number](algebraic-number.md)  
🏷️ **Tags:** [Quadratically closed field](quadratically-closed-field.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/en.wikipedia.org/w/index.php?title=Algebraic_number&oldid=1168427661#Field)

The set of all [algebraic numbers](algebraic-number.md) forms a [field](field-mathematics.md).

This field contains all of the [rational numbers](rational-number.md), but it is a [quadratically closed field](quadratically-closed-field.md).

Like the [rationals](rational-number.md), this field also has the same [cardinality](cardinality.md) as the [natural numbers](natural-number.md), because we can specify and enumerate each of its members by a fixed number of integers from the [polynomial equation](algebraic-equation.md) that defines them. So it is a bit like the [rationals](rational-number.md), but we use potentially arbitrary numbers of integers to specify each number (polynomial coefficients + index of which root we are talking about) instead of just always two as for the rationals.

Each [algebraic number](algebraic-number.md) also has a degree associated to it, i.e. the [degree of the polynomial](degree-of-a-polynomial.md) used to define it.
