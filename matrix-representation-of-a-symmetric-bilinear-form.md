# Matrix representation of a symmetric bilinear form

↑ **Parent:** [Symmetric bilinear form](symmetric-bilinear-form.md)

Like the [matrix representation of a bilinear form](matrix-representation-of-a-bilinear-form.md), it is a [matrix](matrix.md), but now the matrix has to be a [symmetric matrix](symmetric-matrix.md).

We can then immediately see that the matrix is symmetric, then so is the form. We have:

$$
B(x,y) = x^T M y
$$

But because $B(x,y)$ is a [scalar](scalar-mathematics.md), we have:

$$
B(x,y) = B(x,y)^T
$$

and:

$$
B(x,y) = B(x,y)^T = (x^T M y)^T = y^T M^T x = y^T M^T x = y^T M x = B(y,x)
$$
