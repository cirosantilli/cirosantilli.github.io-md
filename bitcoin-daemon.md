# Bitcoin daemon

↑ **Parent:** [Bitcoin Core executable](bitcoin-core-executable.md)

Runs just a headless Bitcoin server.

You can then interact with it via the [Bitcoin CLI client](bitcoin-cli-client.md).

On [Bitcoin Core snap](bitcoin-core-snap.md) 26.0, the executable is called `bitcoin-core.daemon` rather than `bitcoind`
