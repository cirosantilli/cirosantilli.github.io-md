# Google Pixel 3a (2020)

↑ **Parent:** [Cell phones](cell-phones.md)

<a id="_212"></a>
Bought: January 2020 from [https://store.google.com/](https://store.google.com/) for 350 pounds.

<a id="_213"></a>
Official specs: [https://support.google.com/pixelphone/answer/7158570?hl=en&ref_topic=7530176](https://support.google.com/pixelphone/answer/7158570?hl=en&ref_topic=7530176)

<a id="_214"></a>
GMS Arena: [https://www.gsmarena.com/google_pixel_3a-9408.php](https://www.gsmarena.com/google_pixel_3a-9408.php)

<a id="_215"></a>
Front camera video on [Android](../android-operating-system.md) 11: about 100MiB / minute. The encoding is however super inefficient, a [FFmpeg](../ffmpeg.md) re-encode without any options reduces it by 1/3.

<a id="_216"></a>
For Fastboot mode: Power and Volume down simultaneously for 10-15s. It is OK if screen sleeps. On "no command", power then volume up to see options.

<a id="_217"></a>
2026-08: same status as 2023-10, managed to get mouse to work, but I forgot the bloody PIN. Doing a factory reset. Gemini instructions worked out perfectly:

<a id="_218"></a>
<a id="_219"></a>
- Press and hold the Power and Volume Down buttons until you see the Fastboot mode screen (triangle with an exclamation point).
<a id="_220"></a>
- Use the volume buttons to highlight Recovery Mode and press the Power button to select it.
<a id="_221"></a>
- If you see an Android robot with "No command," press and hold the Power button, press Volume Up once, then release Power.
<a id="_222"></a>
- Scroll to Wipe data/factory reset using the volume buttons and press Power.
<a id="_223"></a>
- Confirm the reset, then select Reboot system now when finished

<a id="_224"></a>
After factory reset, boot requires motherfucking pin or Google account to unlock the phone. But managed with Google account.

<a id="_225"></a>
Noticed that the battery on that phone seems also very unreliable, is getting very warm very fast and sometimes shuts down because of it, and discharges very fast. So I have to switch between power and usb cable for mouse/keyboard fast like crazy to keep it going through operations.

<a id="_226"></a>
2023-10: touchscreen not registering touches anymore. Still displays images. Manage to regain access with wired USB mouse + a simple USB-C adapter. RIP. Will attempt replacement: [https://store.ifixit.co.uk/products/google-pixel-3a-screen-genuine?variant=42388954448071](https://store.ifixit.co.uk/products/google-pixel-3a-screen-genuine?variant=42388954448071), partly to get [Authy](../authy.md) access which I had never properly tested... Replaced screen, but at exact same status as before: shows image but no touch. thus I wasted my money and time (minus the learning) something else is broken.
