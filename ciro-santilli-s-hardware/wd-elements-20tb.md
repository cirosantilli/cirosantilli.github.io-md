# WD Elements 20TB

↑ **Parent:** [External storage](external-storage.md)

<a id="_542"></a>
Bought December 2023 for 300 pounds, so 15 pounds / TB. Needs power supply unfrotunately besides USB, the largest one without needing power supply was only 5 TB at the time so not worth it, given that my [P14s](lenovo-thinkpad-p14s-gen4-amd.md) alreay carriers 2 TB. 10x is a must for the external crap.

The size is reasonable, not megaportable, but definitely reasonable.
