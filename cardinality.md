# Cardinality

↑ **Parent:** [Set (mathematics)](set-mathematics.md)

The size of a set.

For [finite](infinity.md) sizes, the definition is simple, and the intuitive name "size" matches well.

But for infinity, things are messier, e.g. the size of the [real numbers](real-number.md) is strictly larger than the size of the [integers](integer.md) as shown by [Cantor's diagonal argument](cantor-s-diagonal-argument.md), which is kind of what justifies a fancier word "cardinality" to distinguish it from the more normal word "size".

The key idea is to compare set sizes with [bijections](bijection.md).
