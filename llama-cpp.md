↑ **Parent:** [Ollama](ollama.md)

[https://ollama.com](https://ollama.com)

This appears to be the backend library of [Ollama](ollama.md).

They have a [CLI](command-line-interface.md) front-end named [llama-cli](llama-cli.md).

[https://askubuntu.com/questions/1461564/install-llama-cpp-locally](https://askubuntu.com/questions/1461564/install-llama-cpp-locally) has some tutorials for [Ubuntu](ubuntu.md). There was no nicely pre-packaged one for [Ubuntu 25.04](ubuntu-25-04.md), but build worked on 79e0b68c178656bb0632cb8602d2940b755077f8 In particular it exposed [Vulkan](vulkan.md) support before [Ollama](ollama.md) did: [https://github.com/ollama/ollama/pull/5059](https://github.com/ollama/ollama/pull/5059) and it did seem to work, using up my [AMD GPU](amd-gpu.md).
