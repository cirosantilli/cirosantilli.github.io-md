# Linear operator

↑ **Parent:** [Linear map](linear-map.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Linear_operator)

We define it as a [linear map](linear-map.md) where the [domain](domain-of-a-function.md) is the same as the [image](image-mathematics.md), i.e. an [endofunction](endofunction.md).

Examples:
- a 2x2 matrix can represent a [linear map](linear-map.md) from [$\R^2$](real-plane.md) to [$\R^2$](real-plane.md), so which is a linear operator
- the [derivative](derivative.md) is a [linear map](linear-map.md) from [$C^{\infty}$](infinitely-differentiable-function.md) to [$C^{\infty}$](infinitely-differentiable-function.md), so which is also a linear operator
