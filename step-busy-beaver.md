# Step busy beaver

↑ **Parent:** [Busy beaver](busy-beaver.md)

The [step busy beaver](step-busy-beaver.md) is a variant of the [busy beaver game](busy-beaver.md) counts the number of steps before halt, instead of the number of 1's written to the tape.

As of 2023, it appears that [BB(5)](bb-5.md) the same machine, , will win both for 5 states. But this is not always necessarily the case.
