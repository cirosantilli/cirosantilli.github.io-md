# Algebraic structure

↑ **Parent:** [Algebra](algebra-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Algebraic_structure)

A [set](set-mathematics.md) $S$ plus any number of functions $f_i : S \times S \to S$, such that each $f_i$ satisfies some properties of choice.

Key examples:
- [group](group-split.md): one function
- [field](field-mathematics.md): two functions
- [ring](ring-mathematics.md): also two functions, but with less restrictive properties
