# Ruby on Rails

↑ **Parent:** [Ruby (programming language)](ruby-programming-language.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ruby_on_Rails)

The only reason why [Ruby](ruby-programming-language.md) exists.

This web framework is pretty good as of 2020 compared to others, because it managed to gain a critical community size, and there's a lot of basic setup already done for you.

it is just big shame it wasn't written in [Python](python-programming-language.md) or even better, [Node.js](node-js-split.md), because learning [Ruby](ruby-programming-language.md) is completely useless for anything else. As of 2020 for example, most [Node.js](node-js-split.md) web frameworks feel like crap compared to Rails, you just have to debug so much there.

Used in [GitLab](gitlab.md), which is why [Ciro Santilli](ciro-santilli-split.md) touched it.
