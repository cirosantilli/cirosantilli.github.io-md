# BVGraph

↑ **Parent:** [Graph file format](graph-file-format.md)

The native file format of [WebGraph](webgraph-software.md).

It is a binary format and highly storage efficient.

It is for example what [Common Crawl web graph](common-crawl-web-graph.md) currently dumps to as of 2025, see e.g.: [https://data.commoncrawl.org/projects/hyperlinkgraph/cc-main-2024-25-dec-jan-feb/index.html](https://data.commoncrawl.org/projects/hyperlinkgraph/cc-main-2024-25-dec-jan-feb/index.html)
