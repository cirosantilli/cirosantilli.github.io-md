# How to cite a book on Wikipedia

↑ **Parent:** [Wikipedia HOWTO](wikipedia-howto.md)

To avoid duplication when citing multiple pages: [Section "How to use a single source multiple times in a Wikipedia article?"](how-to-use-a-single-source-multiple-times-in-a-wikipedia-article.md)

A good big sample definition:
```
<ref name="googleStory">{{cite book |last1=Vise |first1=David |author-link1=David A. Vise |last2=Malseed |first2=Mark |author-link2=Mark Malseed |title=The Google Story |date=2008 |publisher=Delacorte Press |url=https://archive.org/details/isbn_9780385342728}}</ref>
```
There is also `title-link` to link to a wiki page. But it is incompatible with `url=` for [Internet Archive Open Library](internet-archive-open-library.md) links which is a shame.
