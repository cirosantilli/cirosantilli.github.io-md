# Polonium-210

↑ **Parent:** [Polonium isotope](polonium-isotope.md)  
🏷️ **Tags:** [Alpha emitter](alpha-decay.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Polonium-210)

The only isotope found on [Earth](earth.md) because it occurs as part of the [uranium 238 decay chain](uranium-238-decay-chain.md), i.e., it is not a [primordial nuclide](primordial-nuclide.md).

Interestingly it is a bit less stable than other [isotopes](isotope.md)L such as [Polonium-208](polonium-208.md) (3 y) and [Polonium-209](polonium-209.md) (124 y), but those aren't in any Earthly radioactive chain so they don't show up on Earth.
