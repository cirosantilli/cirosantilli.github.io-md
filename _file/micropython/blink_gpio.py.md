<h1 id="_file/micropython/blink_gpio.py">micropython/blink_gpio.py</h1>

↑ **Parent:** [MicroPython example](../../micropython-example.md)

Toggle pin 0 twice per second. This could be used for example to blink LED on pin 0 once per second with this test circuit:

```
BOARD__1gp0____3gnd
       |       |
       R_2k    |
       |       |
       +-aLEDc-+
```

Tested on:

- [RPI Pico W](../../raspberry-pi-pico-w.md)
