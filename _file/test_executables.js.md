<h1 id="_file/test_executables.js">test_executables.js</h1>

↑ **Parent:** [Software testing](../software-testing.md)

This script tests all executables under a selected directory.

[Ciro Santilli](../ciro-santilli-split.md) has been writing scripts of that type for a long time in order to test his [programming self-learning setups with asserts](../ciro-santilli-s-documentation-superpowers.md).

The most advanced of those being the [test system](https://github.com/cirosantilli/linux-kernel-module-cheat/blob/9b6552ab6c66cb14d531eff903c4e78f3561e9ca/test) of [Linux Kernel Module Cheat](../linux-kernel-module-cheat-split.md).

But had too much stuff that would be specific to that project, so Ciro decided to start this new one in [Node.js](../node-js-split.md), hopefully it will also be the last he ever writes.

A sample usage of the test library can be seen at: [nodejs/sequelize/test](nodejs/sequelize/test).
