↑ **Parent:** [Numpy.fft](../../numpy-fft.md)

Generates `numpy/fft_plot.svg`, the plot of $2 \sin(t) +  \cos(4t)$ with 25 points and its [DFT](../../discrete-fourier-transform.md).

The output was also uploaded to: [https://commons.wikimedia.org/wiki/File:DFT_2sin(t)_%2B_sin(4t).svg](https://commons.wikimedia.org/wiki/File:DFT_2sin(t)_%2B_sin(4t).svg) and added to [https://en.wikipedia.org/w/index.php?title=Discrete_Fourier_transform&oldid=1176616763](https://en.wikipedia.org/w/index.php?title=Discrete_Fourier_transform&oldid=1176616763) only to be later removed of course: [Deletionism on Wikipedia](../../deletionism-on-wikipedia.md).
