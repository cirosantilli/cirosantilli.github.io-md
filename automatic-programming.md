# Automatic programming

↑ **Parent:** [Compiler](compiler.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Automatic_programming)

We use the term "automatic programming" to mean "generating code from [natural language](natural-language.md)".

The ultimate high level of which is of course to program with:

> computer, make [money](money.md)

which is basically the goal of [artificial general intelligence](artificial-general-intelligence.md), especially according to [The Employment Test](the-employment-test.md) definition of [AGI](artificial-general-intelligence.md).

The term has not always had that sense:

> automatic programming has always been a euphemism for programming in a higher-level language than was then available to the programmer

sums it up.

But in the current [AI boom](ai-boom.md), this is the sense that matters, so that's what we will go with.
