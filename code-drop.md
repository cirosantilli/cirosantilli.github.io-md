[Open source](open-source-software.md) development model in which developers develop in private, and only release code to the public during releases.

Notable example project: [Android Open Source Project](android-open-source-project.md).

This development model basically makes reporting bugs and sending patches a waste of time, because many of them will already have been solved, which is why this development model is [evil](evil.md).
