# Principal quantum number

↑ **Parent:** [Quantum number](quantum-number.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Principal_quantum_number)

Determines energy. This comes out directly from the resolution of the [Schrödinger equation solution for the hydrogen atom](schrodinger-equation-solution-for-the-hydrogen-atom.md) where we have to set some arbitrary values of energy by [separation of variables](separation-of-variables.md) just like we have to set some arbitrary numbers when [solving partial differential equations with the Fourier series](solving-partial-differential-equations-with-the-fourier-series.md). We then just happen to see that only certain integer values are possible to satisfy the equations.
