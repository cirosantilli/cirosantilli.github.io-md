<a id="_60"></a>
The cqcounter screenshots don't offer too much information, but having the wayback machine ones could actually reveal new fingerprints and other website information leaks.

<a id="_61"></a>
We've had a very quick look, and while there was nothing mind blowing, there were some small finds.

<a id="_62"></a>
Starting [December 2004, the "Submit your favored carlson quote" of alljohnny.com](https://web.archive.org/web/20041215182457/http://alljohnny.com/index.html) was mind blowingly switched to point to [https://washington.serversecured.net/~alljohnn/cgi-bin/memlog.cgi](https://web.archive.org/web/20050328224840/https://washington.serversecured.net/~alljohnn/cgi-bin/memlog.cgi) thus likely leaking the control site URL. Beauty. It previously pointed to [https://web.archive.org/web/20040901162621/https://secure.alljohnny.com/cgi-bin/memlog.cgi](https://web.archive.org/web/20040901162621/https://secure.alljohnny.com/cgi-bin/memlog.cgi)

<a id="_63"></a>
[mynepalnews.com](https://web.archive.org/web/20110203000411/http://mynepalnews.com/) actually has several archives for a [/stats](https://web.archive.org/web/20110204095803/http://mynepalnews.com:80/stats/) path which contains HTML reports generated by Webalizer, an analytic tracker that tracks the source of incoming traffic!!! It is hard to believe that the CIA would have left that there. Particularly ridiculous is the presence of `inurl:cgi server_software` at [https://web.archive.org/web/20110204095809/http://mynepalnews.com:80/stats/usage_200805.html](https://web.archive.org/web/20110204095809/http://mynepalnews.com:80/stats/usage_200805.html) which is almost certainly a [Google dork](https://ourbigbook.com/go/topic/google-dork) search, which we know is something that the Iranians used to find the websites. That search hits under [/cgi-bin/check.cgi](https://web.archive.org/web/20110204095351/http://mynepalnews.com:80/cgi-bin/check.cgi). That page is itself os some interest containing `SERVER_ADMIN = mmadev@mmadev.com`. [https://web.archive.org/web/20110204095815/http://mynepalnews.com:80/stats/usage_200806.html](https://web.archive.org/web/20110204095815/http://mynepalnews.com:80/stats/usage_200806.html) also reveals several request IPs. Even if this is not a CIA website, there's a chance we could find the IP of the Iranian counter-intelligence in these IP list, it's mind blowing. There's lots of referrer spam too as well. Further HTML inspection however seems to show close relationship to that HTML and other confirmed hits.

<a id="_64"></a>
[globaltourist.net](https://web.archive.org/web/20101024140137/http://globaltourist.net/), if is actually a hit, likely has a [a 2003 archive](https://web.archive.org/web/20031221163711/http://globaltourist.net/), which would be our earliest hit archive so far.

<a id="_65"></a>
A fun fact is that looking at the source code of: [https://web.archive.org/web/20130828122833/http://euronewsonline.net/euro_bus.php](https://web.archive.org/web/20130828122833/http://euronewsonline.net/euro_bus.php) we noticed an interesting comment:<a id="_66"></a>

```
<!-- ImageReady Slices (enewsweather.psd) -->
```
which clarifies that the CIA likely used Adobe ImageReady to cut up the images for [Split header images](../cia-2010-covert-communication-websites/split-header-images.md):<a id="_67"></a>


> Adobe ImageReady was a bitmap graphics editor that was shipped with Adobe Photoshop for six years. It was available for Windows, Classic Mac OS and Mac OS X from 1998 to 2007. ImageReady was designed for web development and closely interacted with Photoshop

We also understand that the tool likely outputs the layout to HTML directly, and leaks the adobe projects filenames (.pds files) in the process.
