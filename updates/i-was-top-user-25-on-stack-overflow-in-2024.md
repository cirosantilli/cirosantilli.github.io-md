# I was top user 25 on Stack Overflow in 2024

↑ **Parent:** [Updates](../updates-split.md)

<a id="_500"></a>
In 2024 I was user \#25 with the most reputation gained on Stack Overflow.

<a id="_501"></a>
This is up from \#38 in 2023 is even though I have answered less questions than before.

<a id="_502"></a>
This is likely because [LLMs](../large-language-model.md) have killed users that just answered lots of easy new questions, and favored those like me who only answer more important questions found through Google.

<a id="_503"></a>
I was \#13 on the last quarter, so this is likely to go even higher in 2025. More details at: [Section "Ciro Santilli's Stack Overflow contributions"](../ciro-santilli-s-stack-overflow-contributions.md)
