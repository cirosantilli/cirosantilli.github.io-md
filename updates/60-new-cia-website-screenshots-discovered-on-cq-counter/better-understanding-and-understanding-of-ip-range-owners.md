I also started to better note down the IP owner and location of each IP range from [viewdns.info](../../viewdns-info.md) at [Hits with nearby IP hits](../../cia-2010-covert-communication-websites/hits-with-nearby-ip-hits.md), as this is an important information which could offer further clues. All IPs in each range belong to the same provider, since IPs are generally bought in blocks. For example:<a id="60-new-cia-website-screenshots-discovered-on-cq-counter/_201"></a>

<a id="60-new-cia-website-screenshots-discovered-on-cq-counter/_202"></a>
- 62.22.60.49 telecom-headlines.com was owned by the company UUNET and hosted from Spain, and the same is true for neighboring IPs such as:<a id="60-new-cia-website-screenshots-discovered-on-cq-counter/_203"></a>

  <a id="60-new-cia-website-screenshots-discovered-on-cq-counter/_204"></a>
  - 62.22.60.48: currentcommunique.com
  <a id="60-new-cia-website-screenshots-discovered-on-cq-counter/_205"></a>
  - 62.22.60.52: collectedmedias.com
<a id="60-new-cia-website-screenshots-discovered-on-cq-counter/_206"></a>
- 63.131.229.12 cyberreportagenews.com was owned by the company ADHOST and hosted from Coeur d'Alene - United States. Interestingly US-based hosts also offer city-level information while foreign ones don't.
These don't necessarily tell us directly who the CIA hosted with, since in some cases hosting providers can indirectly rent out IPs from other providers, e.g. Heroku uses AWS. But it does suggest that some nearby IP ranges were done on the same hosting provider while others weren't.
