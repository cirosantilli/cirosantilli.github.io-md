I tried to use every single free offline [text-to-speech](../text-to-speech.md) engine that would run on [Ubuntu 24.04](../ubuntu-24-04.md) without too much hassle to see if any of them sounded natural. [pico2wave](https://ourbigbook.com/go/topic/pico2wave) was the overall winner so far, but it is not perfect.

<a id="_642"></a>
I've been noticing a gap between the "[AI](../artificial-intelligence-split.md)" [SOTA](../state-of-the-art.md) and what is actually packaged well enough to be usable by a general audience.
