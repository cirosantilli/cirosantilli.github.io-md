# Spacetime diagram

↑ **Parent:** [Spacetime](spacetime.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Spacetime_diagram)

Why should I care when I can calculate new x and new time with [Lorentz transformation](lorentz-transformation.md)?

Answer: it can give some qualitative intuition on what is larger/smaller happens before/after based only on arguably more intuitive geometric considerations, without requiring you to do any calculations, see e.g. [Figure "Spacetime diagram illustrating how faster-than-light travel implies time travel"](faster-than-light-implies-time-travel.md#image-spacetime-diagram-illustrating-how-faster-than-light-travel-implies-time-travel).
