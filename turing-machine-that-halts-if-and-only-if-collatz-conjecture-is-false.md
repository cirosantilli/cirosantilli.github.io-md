# Turing machine that halts if and only if Collatz conjecture is false

↑ **Parent:** [Conjecture reduction to a halting problem](conjecture-reduction-to-a-halting-problem.md)  
🏷️ **Tags:** [Collatz conjecture](collatz-conjecture.md)

[https://mathoverflow.net/questions/309044/is-there-a-known-turing-machine-which-halts-if-and-only-if-the-collatz-conjectur](https://mathoverflow.net/questions/309044/is-there-a-known-turing-machine-which-halts-if-and-only-if-the-collatz-conjectur) suggests one does not exist. Amazing.

Intuitively we see that the situation is fundamentally different from the [Turing machine that halts if and only if the Goldbach conjecture is false](turing-machine-that-halts-if-and-only-if-the-goldbach-conjecture-is-false.md) because for Collatz the counter example must go off into infinity, while in Goldbach conjecture we can finitely check any failures.

Amazing.
