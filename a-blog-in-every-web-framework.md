# A blog in every web framework

↑ **Parent:** [Hello world website](hello-world-website.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/A_blog_in_every_web_framework)

A (multi-user) [blog](blog.md) is the [hello world](hello-world-program.md) of the web, so creating one of those is the best way to quickly evaluate web technology, i.e. [time to Hello World](time-to-hello-world.md).

Some new frameworks like [FeathersJS](feathersjs.md) are making a chat app instead, as that highlights the push notifications a bit better.
