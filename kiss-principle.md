# KISS principle

↑ **Parent:** [Ciro Santilli's software engineering wisdom](ciro-santilli-s-software-engineering-wisdom.md)  
🏷️ **Tags:** [Simplicity is the ultimate sophistication](simplicity-is-the-ultimate-sophistication.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/KISS_principle)

The software engineer phrasing of [simplicity is the ultimate sophistication](simplicity-is-the-ultimate-sophistication.md).

Like all other principles, it is not absolute.

But it is something that you should always have on the back of your mind.

[You aren't gonna need it](you-aren-t-gonna-need-it.md) is closely related, as generally the extra unnecessary complications are set in place to accommodate useless features that will never be needed.
