# Local symmetry

↑ **Parent:** [Continuous symmetry](continuous-symmetry.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Local_symmetry)

Local symmetries appear to be a synonym to [internal symmetry](internal-symmetry.md), see description at: [Section "Internal and spacetime symmetries"](internal-and-spacetime-symmetries.md).

As mentioned at [Quote ](why-do-symmetries-such-as-su-3-su-2-and-u-1-matter-in-particle-physics.md#quote-axelmaas-local-symmetry), local symmetries map to forces in the [Standard Model](standard-model-split.md).

Appears to be a synonym for: [gauge symmetry](gauge-symmetry.md).

A local symmetry is a transformation that you apply a different transformation for each point, instead of a single transformation for every point.
