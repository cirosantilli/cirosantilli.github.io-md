# Josephson phase

↑ **Parent:** [Josephson equations](josephson-equations.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Josephson_phase)

A function $\R \to \R$ defined by the second of the [Josephson equations](josephson-equations.md) plus initial conditions.

It represents an internal state of the junction.
