# It surely would be intolerable not to know

↑ **Parent:** [Simple to state but hard to prove](simple-to-state-but-hard-to-prove.md)  
🏷️ **Tags:** [Quote](quote.md)

A beautiful quote fom Edward Titchmarsh:[https://mathshistory.st-andrews.ac.uk/Biographies/Titchmarsh/quotations/](https://mathshistory.st-andrews.ac.uk/Biographies/Titchmarsh/quotations/)

> It can be of no practical use to know that [pi](pi.md) is [irrational](irrational-number.md), but if we can know, it surely would be intolerable not to know.

[Ciro Santilli](ciro-santilli-split.md) believes that it is perhaps for this reason that [simple to state but hard to prove](simple-to-state-but-hard-to-prove.md) theorems are so attractive.

This quote was brought to [Ciro Santilli](ciro-santilli-split.md)'s attention at: [https://www.quantamagazine.org/recounting-the-history-of-maths-transcendental-numbers-20230627/](https://www.quantamagazine.org/recounting-the-history-of-maths-transcendental-numbers-20230627/)
