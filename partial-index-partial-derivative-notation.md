# Partial index partial derivative notation

↑ **Parent:** [Partial derivative notation](partial-derivative-notation.md)

This notation is not so common in basic mathematics, but it is so incredibly convenient, especially with [Einstein notation](einstein-notation.md) as shown at [Section "Einstein notation for partial derivatives"](einstein-notation-for-partial-derivatives.md):

$$
\partial_0 F(x, y, z) = \pdv{F(x, y, z)}{x} \\
\partial_1 F(x, y, z) = \pdv{F(x, y, z)}{y} \\
\partial_2 F(x, y, z) = \pdv{F(x, y, z)}{x} \\
$$

This notation is similar to [partial label partial derivative notation](partial-label-partial-derivative-notation.md), but it uses indices instead of labels such as $x$, $y$, etc.
