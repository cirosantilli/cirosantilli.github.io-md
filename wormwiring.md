# WormWiring

↑ **Parent:** [WormAtlas](wormatlas.md)

[https://wormwiring.org/](https://wormwiring.org/)

This contains the [C. elegans](caenorhabditis-elegans.md) connectome.

The browseable thing is this massive interactive [PDF](pdf.md): [https://wormwiring.org/papers/Interactive-Diagram.pdf](https://wormwiring.org/papers/Interactive-Diagram.pdf). It lists [neurons](neuron.md) from the [C. elegans cell lineage](c-elegans-cell-lineage.md) using the standard cell names, and how they connect to each other. Some make a surprising ammount of connections.
