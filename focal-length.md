# Focal length

↑ **Parent:** [Biconvex spherical lens](biconvex-spherical-lens.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Focal_length)

If you pass [parallel light](parallel-light.md).

For a [biconvex spherical lens](biconvex-spherical-lens.md), it is given by:

$$
\frac{1}{f} = n \left( \frac{1}{R_1} + \frac{1}{R_2} \right)
$$

where:
- n: f nidnex
