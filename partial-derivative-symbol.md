# Partial derivative symbol

↑ **Parent:** [Partial derivative notation](partial-derivative-notation.md)  
🏷️ **Tags:** [Mathematical symbol that looks like a Greek letter but isn't](mathematical-symbol-that-looks-like-a-greek-letter-but-isn-t.md)

Nope, it is not a [Greek letter](greek-alphabet.md), notably it is not a lowercase [delta](delta-letter.md). It is just some random made up symbol that looks like a [letter D](d.md). Which is of course derived from [delta](delta-letter.md), which is why it is all so damn confusing.

I think the symbol is usually just read as "[D](d.md)" as in "d f d x" for $\pdv{F(x, y, z)}{x}$.
