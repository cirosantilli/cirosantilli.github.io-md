# Video random-access memory

↑ **Parent:** [Graphics processing unit](graphics-processing-unit.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Video_random-access_memory)

In [discrete GPUs](discrete-gpu.md), [VRAM](video-random-access-memory.md) is [RAM](random-access-memory.md) memory that lives on the [GPU](graphics-processing-unit.md)'s [PCB](printed-circuit-board.md).

They are located in separate chips to the GPU's compute, since just like for [CPUs](central-processing-unit.md), you can't put both on the same [chip](integrated-circuit.md) as the manufacturing processes are different and incompatible.

[Integrated GPUs](integrated-gpu.md) don't have [VRAM](video-random-access-memory.md) and just instead use the same [RAM](random-access-memory.md) as the [CPU](central-processing-unit.md).
