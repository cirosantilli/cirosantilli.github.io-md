# Standard Model

↑ **Parent:** [Particle physics](particle-physics-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Standard_Model)

As of 2019, the more formal name for [particle physics](particle-physics-split.md), which is notably missing [general relativity](general-relativity.md) to achieve the [theory of everything](theory-of-everything.md).

[https://cds.cern.ch/record/799984/files/0401010.pdf](https://cds.cern.ch/record/799984/files/0401010.pdf) The Making of the Standard Model by Steven Weinberg mentions three crucial elements that made up the standard model post earlier less generalized [quantum electrodynamics](quantum-electrodynamics.md) understandings
- [quark](quark.md)
- [gauge symmetry](gauge-symmetry.md)
- [spontaneous symmetry breaking](spontaneous-symmetry-breaking.md)
