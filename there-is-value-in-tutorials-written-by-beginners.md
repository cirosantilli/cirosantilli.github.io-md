# There is value in tutorials written by beginners

↑ **Parent:** [Cirism](cirism-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/There_is_value_in_tutorials_written_by_beginners)

[Ciro Santilli](ciro-santilli-split.md) is a big believer that there is value in tutorials written by beginners, because beginners are more likely to explain things in a way that other beginners can understand.

Even though they make more mistakes, this more approachable point of view can be very valuable.

And mistakes/omissions can be corrected on comments by people with more knowledge, so that the writer also ends up learning something new.
