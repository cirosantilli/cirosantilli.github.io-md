# Infinity

↑ **Parent:** [Limit (mathematics)](limit-mathematics.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Infinity)

> Chuck Norris counted to infinity. Twice.

There are a few related concepts that are called infinity in [mathematics](mathematics-split.md):
- [limits](limit-mathematics.md) that are greater than any number
- the [cardinality](cardinality.md) of a [set](set-mathematics.md) that does not have a finite number of elements
- in some number systems, there is an explicit "element at infinity" that is not a [limit](limit-mathematics.md), e.g. [projective geometry](projective-geometry.md)
