# Game of chance

↑ **Parent:** [Non-deterministic game](non-deterministic-game.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Game_of_chance)

The definition is not very precise, as in many games with random elements there is a mixture of both skill and luck.

So we just use the precise [Non-deterministic game](non-deterministic-game.md) term instead for any game that has any random element beyond the control of the players.
