# lspci

↑ **Parent:** [PCI](pci.md)

`lspci` is the name of several versions of [CLI tools](command-line-utility.md) used in [UNIX](unix.md)-like systems to query information about [PCI](pci.md) devices in the system.

On [Ubuntu 23.10](ubuntu-23-10.md), it is provided by the [pciutils](pciutils.md) package, which is so dominant that when we say "lspci" without qualitication, that's what we mean.
