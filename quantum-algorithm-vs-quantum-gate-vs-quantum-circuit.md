# Quantum algorithm vs quantum gate vs quantum circuit

↑ **Parent:** [Quantum algorithm](quantum-algorithm.md)

There is no fundamental difference between them, a [quantum algorithm](quantum-algorithm.md) is a [quantum circuit](quantum-circuit.md), which can be seen as a super complicated [quantum gate](quantum-logic-gate.md).

Perhaps the greats practical difference is that algorithms tend to be defined for an arbitrary number of N qubits, i.e. as a [function](function-mathematics.md) for that each N produces a specific [quantum circuit](quantum-circuit.md) with N [qubits](qubit.md) solving the problem. Most named gates on the other hand have fixed small sizes.
