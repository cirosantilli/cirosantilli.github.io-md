# Fingerprints

<a id="_4540"></a>
From [The Reuters websites](the-reuters-websites.md) and others we've found, we can establish see some clear stylistic trends across the websites which would allow us to find other likely candidates upon inspection:<a id="_4541"></a>

<a id="_4542"></a>
- natural sounding, sometimes long-ish, [domain names](../domain-name.md) generally with 2 or 3 full words. Most in English language, but a few in Spanish, and very few in other languages like French.
<a id="_4543"></a>
- shallow websites with a few tabs, many external links, sometimes many images, and few internal pages
<a id="_4544"></a>
- common themes include:<a id="_4545"></a>

  <a id="_4546"></a>
  - news
  <a id="_4547"></a>
  - hobbies, notably sports, travel and [photography](../photography.md). Golf seems overrepresented. Must be a thing over there in Langley.
<a id="_4548"></a>
- .com and .net [top-level domains](../top-level-domain.md), plus a few other very rare [non .com .net TLDs](non-com-net-tlds.md), notably .info and .org
<a id="_4549"></a>
- each one has one "communication mechanism file": [communication mechanisms](communication-mechanism.md)
<a id="_4550"></a>
- narrow page width like in the days of old, lots of images
<a id="_4551"></a>
- [split header images](split-header-images.md)
<a id="_4552"></a>
- some common pattern they follow in their news lists:<a id="_4553"></a>

  <a id="_4554"></a>
  - `ul.rss-items > li.rss-item`, e.g.: [https://web.archive.org/web/20110202092126/http://beamingnews.com/](https://web.archive.org/web/20110202092126/http://beamingnews.com/)
  <a id="_4555"></a>
  - links with class `a.newslink` and `a.newslinkalt` e.g. [https://web.archive.org/web/20110128181622/http://profile-news.com/](https://web.archive.org/web/20110128181622/http://profile-news.com/)
The most notable dissonance from the rest of the web is that there are no commercial looking website of companies, presumably because it was felt that it would be possible to verify the existence of such companies.

<a id="_4556"></a>
Most domains are the only domain for its IP, i.e. the websites are mostly private hosted. However we have later found many exceptions to this general indicator, so it should not be used as a strong exclusion rule.
