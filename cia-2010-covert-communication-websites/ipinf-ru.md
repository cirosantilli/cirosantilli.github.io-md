<a id="_6403"></a>
OK, [Oleg Shakirov's findings](oleg-shakirov-s-findings.md) inspired [Ciro Santilli](../ciro-santilli-split.md) to try [Yandexing](../yandex.md) a bit more...

<a id="_6404"></a>
`alljohnny.com` had a hit: [https://ipinf.ru/domains/alljohnny.com/](https://ipinf.ru/domains/alljohnny.com/), and so Ciro started looking around... and a good number of other things have hits.

<a id="_6405"></a>
Not all of them, definitely less data than [viewdns.info](viewdns-info.md).

<a id="_6406"></a>
But they do reverse IP, and they show which nearby reverse IPs have hits on the same page, for free, which is great!

<a id="_6407"></a>
Shame their ordering is purely alphabetical, doesn't properly order the IPs so it is a bit of a pain, but we can handle it.

<a id="_6408"></a>
OMG, [Russians](../russia.md)!!!

<a id="_6409"></a>
The data here had a little bit of non-overlap from other sources. 4 new confirmed hits were found, plus 4 possible others that were left as candidates.
