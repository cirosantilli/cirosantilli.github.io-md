# Are there .org hits?

↑ **Parent:** [Non .com .net TLDs](non-com-net-tlds.md)

<a id="_5958"></a>
Previously it was unclear if there were any .org hits, until we found the first one with clear [comms](communication-mechanism.md): [https://web.archive.org/web/20110624203548/http://awfaoi.org/hand.jar](https://web.archive.org/web/20110624203548/http://awfaoi.org/hand.jar)

<a id="_5959"></a>
Later on, two more clear ones were found with [expired domain trackers](expired-domain-trackers.md):<a id="_5960"></a>

<a id="_5961"></a>
- azerinews.org
<a id="_5962"></a>
- autism-news.org
further settling their existence. Later on newimages.org also came to light.

<a id="_5963"></a>
Others that had been previously found in IP ranges but without clear comms:<a id="_5964"></a>

<a id="_5965"></a>
- 65.61.127.177: material-science.org
<a id="_5966"></a>
- 212.4.17.61: tech-stop.org
<a id="_5967"></a>
- 74.116.72.244 arborstribune.org

<a id="_5968"></a>
.org is very rare, and has been excluded from some of our search heuristics. That was a shame, but likely not much was missed.
