<a id="_217"></a>
The main criteria to consider a website as a hit is for it to have a [Wayback Machine](wayback-machine.md) archive with an archived [communication mechanism](communication-mechanism.md). [JS comms](js-comms.md) are always quickly visually inspected, other mechanisms we look only at filename patterns for now. We also consider as hits websites that don't have archived comms, often the case for [CGI comms](cgi-comms.md), but which have two ore more of the following supporting evidence:<a id="_218"></a>

<a id="_219"></a>
- shares an IP range with other website
<a id="_220"></a>
- a Wayback Machine archive or [cqcounter](cqcounter.md) screenshot strongly confirming visual style
<a id="_221"></a>
- an archived broken link to the possible comms
Commented edge cases that didn't make the cut can be found mostly under [Section "IP range search"](ip-range-search.md) and [Section "2013 DNS Census virtual host cleanup heuristic keyword searches"](2013-dns-census-virtual-host-cleanup-heuristic-keyword-searches.md).
