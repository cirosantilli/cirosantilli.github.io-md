# Non .com .net TLDs

↑ **Parent:** [TODO](todo.md)

.com and .net are very dominant. Here we list other choices made:
- `.info`: has a few hits:
  - archived [comms](communication-mechanism.md):
    - beyondthefringe.info
  - unarchived [comms](communication-mechanism.md):
    - crickettoday.info
  - unarchived:
    - talkingpointnews.info
    - theventurenews.info
    - worldconcerns.info

  Did a full [Wayback Machine CDX scanning](wayback-machine-cdx-scanning.md) on .info after:
  ```
  grep -e news -e noticias -e nouvelles -e world -e global
  ```

  That makes about 10k domains, so it's about the right size.
- `.org`: has a least one hit, see: [Are there .org hits?](are-there-org-hits.md)
- `.biz`:
  - unarchived [comms](communication-mechanism.md):
    - atthemovies.biz
