# Quantum control system

↑ **Parent:** [Quantum software](quantum-software.md)

Some people call it "operating System".

The main parts of those systems are:
- sending multiple signals at very precise times to the system
- reading out some [quantum error correction](quantum-error-correction.md) bits and sending error correcting signals back in a control loop
