# Machine learning as a form of data compression

↑ **Parent:** [Overfitting](overfitting.md)  
🏷️ **Tags:** [Overfitting](overfitting.md)

Philosophically, machine learning can be seen as a form of [lossy compression](lossy-compression.md).

And if we make it too [lossless](lossless-compression.md), then we are basically [overfitting](overfitting.md).
