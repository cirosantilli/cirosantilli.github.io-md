# Azimuthal quantum number

↑ **Parent:** [Quantum number](quantum-number.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Azimuthal_quantum_number)

Fixed [total angular momentum](total-angular-momentum-operator.md).

The direction however is not specified by this number.

To determine the [quantum angular momentum](angular-momentum-operator.md), we need the [magnetic quantum number](magnetic-quantum-number.md), which then selects which orbital exactly we are talking about.
