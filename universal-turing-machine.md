# Universal Turing machine

↑ **Parent:** [Turing machine](turing-machine.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Universal_Turing_machine)

A Turing machine that simulates another Turing machine/input pair that has been encoded as a string.

In other words: an [emulator](emulator.md)!

The concept is fundamental to state several key results in [computer science](computer-science-split.md), notably the [halting problem](halting-problem.md).
