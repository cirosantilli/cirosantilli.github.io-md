# MAC address

↑ **Parent:** [Internet protocol suite](internet-protocol-suite.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/MAC_address)

Hardcoded and unique network addresses for every single device on [Earth](earth.md).

Started with 48 bits (6 bytes), usually given as 01:23:45:67:89:AB but people now encouraged to use 64-bit ones.

How they are assigned: [https://www.quora.com/How-are-MAC-addresses-assigned](https://www.quora.com/How-are-MAC-addresses-assigned) Basically [IEEE](institute-of-electrical-and-electronics-engineers.md) gives out the 3 first bytes to device manufacturers that register, this is called the [organizationally unique identifier](organizationally-unique-identifier.md), and then each manufacturer keeps their own devices unique.
