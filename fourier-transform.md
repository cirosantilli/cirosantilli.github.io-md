# Fourier transform

↑ **Parent:** [Fourier series](fourier-series.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Fourier_transform)

Continuous version of the [Fourier series](fourier-series.md).

Can be used to represent functions that are not periodic: [https://math.stackexchange.com/questions/221137/what-is-the-difference-between-fourier-series-and-fourier-transformation](https://math.stackexchange.com/questions/221137/what-is-the-difference-between-fourier-series-and-fourier-transformation) while the [Fourier series](fourier-series.md) is only for periodic functions.

Of course, every function defined on a finite line segment (i.e. a [compact space](compact-space.md)).

Therefore, the [Fourier transform](fourier-transform.md) can be seen as a generalization of the [Fourier series](fourier-series.md) that can also decompose functions defined on the entire [real line](real-line.md).

As a more concrete example, just like the [Fourier series](fourier-series.md) is how you solve the [heat equation](heat-equation.md) on a line segment with [Dirichlet boundary conditions](dirichlet-boundary-condition.md) as shown at: [Section "Solving partial differential equations with the Fourier series"](solving-partial-differential-equations-with-the-fourier-series.md), the [Fourier transform](fourier-transform.md) is what you need to solve the problem when the [domain](domain-of-a-function.md) is the entire [real line](real-line.md).
