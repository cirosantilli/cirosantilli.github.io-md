# New International Version

↑ **Parent:** [Version of the bible](version-of-the-bible.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/New_International_Version)

Direct translation from oldest documents deemed reliable, originally in a mixture of Hebrew, Aramaic, and Greek. Interesting project.

This is notably opposed to the approach taken by many versions which were based on the [Septuagint](septuagint.md), which was a much earlier full-Greek translation.
