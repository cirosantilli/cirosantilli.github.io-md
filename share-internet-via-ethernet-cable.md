# Share Internet via Ethernet cable

↑ **Parent:** [Linux networking HOWTO](linux-networking-howto.md)

E.g. to give Compueter 2 Internet in a setup like:
```
Internet --- Wi-Fi --- Computer 1 --- Ethernet --- Computer 2
```
Can be tested e.g. by turning off Wi-Fi from Computer 2 if it has one.

Got it working: [https://askubuntu.com/questions/3063/share-wireless-connection-with-wired-ethernet-port/1502850#1502850](https://askubuntu.com/questions/3063/share-wireless-connection-with-wired-ethernet-port/1502850#1502850)
