# AlphaEvolve

↑ **Parent:** [AI code generation framework that tries to run code](ai-code-generation-framework-that-tries-to-run-code.md)

Blog post: [https://deepmind.google/discover/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/](https://deepmind.google/discover/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/)

[Whitepaper](white-paper.md): [https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/AlphaEvolve.pdf](https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/AlphaEvolve.pdf)

Basically they require users to hand-code a metric and provide a program skeleton with some parts of the code marked to be replaced, and then the system focuses on modifying the code regions in question to optimize the metric.

All the novel results they announced were in [constraint satisfaction problems](constraint-satisfaction-problem.md) or [optimization problem](optimization-problem.md). Their results are still awesome, but it's not very different from [AlphaGo](alphago.md) style things.
