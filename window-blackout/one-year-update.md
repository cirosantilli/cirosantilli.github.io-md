# One year update

↑ **Parent:** [Total Blackout Cassette Roller Blind from Order Blinds Online](total-blackout-cassette-roller-blind-from-order-blinds-online.md)

<a id="_20"></a>
One problem popped up about one year after having bought the blinds in 2019: the blind won't stay still except at the most closed position. Anywhere above it started to slowly go up by itself.

<a id="_21"></a>
It is not super serious as it covers the two main use cases: full closed and fully open, but it is a bit worrying.

<a id="_22"></a>
Also, we've had some [mold](../mold.md) grow on the window, so it is something to look out for, and add some mold spray as it comes up. The fact that the window is dark makes the mold harder to spot.
