# Superconducting phase diagram

↑ **Parent:** [Superconductivity](superconductivity.md)  
🏷️ **Tags:** [Phase transition](phase-transition.md)

There are various possibilities for the axes, but some common ones:
- temperature (T) vs magnetic field strength (B)
- temperature (T) vs proportion of each [chemical element](chemical-element.md) of a [binary alloy](binary-alloy.md)
- temperature (T) vs pressure
