**[Figure 5](#_513)** [Source](https://commons.wikimedia.org/wiki/File:HP_BladeSystem_c7000_Enclosure.jpg). Good image from [Wikimedia Commons](wikimedia-commons.md). In this one we can see how the blades are put vertically, and you get several of them per horizontal rack space, instead of a tipical single [rack server](rack-server.md) going all the way horizontally.

<a id="video-hp-blade-server-by-brian-kirsch-2013"></a>
**[Video 20](#video-hp-blade-server-by-brian-kirsch-2013). HP Blade Server by Brian Kirsch (2013)** [Source](https://www.youtube.com/watch?v=RsZjjAqlpJ0). Featuring an HP DL380 blade server, presumably an older model of this series: [https://buy.hpe.com/uk/en/servers/proliant-dl-servers/proliant-dl300-servers/proliant-dl380-server/hpe-proliant-dl380-gen10-server/p/1010026818](https://buy.hpe.com/uk/en/servers/proliant-dl-servers/proliant-dl300-servers/proliant-dl380-server/hpe-proliant-dl380-gen10-server/p/1010026818).

In the video we can see that it contains [RAM](random-access-memory.md), [disk storage](disk-storage.md), we are told about two [CPUs](central-processing-unit.md), and networking interfaces, so it is a complete [computer](computer-split.md) on its own. He also explains that unlike typical [rack servers](rack-server.md), each blade unit does not have its own coolers and power supply related hardware, which goes instead on the chassis.
