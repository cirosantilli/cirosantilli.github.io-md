# The perfect privacy messaging software features

↑ **Parent:** [Instant messaging](instant-messaging.md)

Haven't found the one yet:
- [open source software](open-source-software.md), doh
- [end-to-end encryption](end-to-end-encryption.md)...
- has browser frontend and [Android](android-operating-system.md) app
- public URL without sharing your mobile phone: [messaging software that force you to have a mobile phone](messaging-software-that-force-you-to-have-a-mobile-phone.md)
- self-destroying messages (turned on by default please)
- user base large enough to give some confidence that it was reviewed for security issues
- easy/built-in setup over [Tor](tor-anonymity-network.md)

Optional but really [ideal](idealism.md):
- can delete messages from the device of the person you sent it to, no matter how old
- decentralized, your username is a public key

The state of messaging is ridiculous as of 2020.
