# Cayley graph

↑ **Parent:** [Generating set of a group](generating-set-of-a-group.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cayley_graph)

You select a [generating set of a group](generating-set-of-a-group.md), and then you name every node with them, and you specify:
- each node by a product of generators
- each edge by what happens when you apply a generator to each element
