# JSON trailing comma

↑ **Parent:** [JSON](json.md)

[https://stackoverflow.com/questions/201782/can-you-use-a-trailing-comma-in-a-json-object](https://stackoverflow.com/questions/201782/can-you-use-a-trailing-comma-in-a-json-object)

The fact that you cannot have trailing commans in lists or dicts as in `3,` at:
```
{
  "asdf": [
    1,
    2,
    3,
  ]
}
```
is one of the most infuriating design choices of all time!!!
