# BLAST (biotechnology)

↑ **Parent:** [Sequence alignment](sequence-alignment.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/BLAST_(biotechnology))

BLAST is a [sequence alignment](sequence-alignment.md).

The [NCBI](national-center-for-biotechnology-information.md) free-to-use BLAST server: [https://blast.ncbi.nlm.nih.gov/Blast.cgi](https://blast.ncbi.nlm.nih.gov/Blast.cgi). Having a centralized query server is fundamental, because the gain of [sequence alignment](sequence-alignment.md) really comes from having one huge database to link information together, which is best centralized.
