# Discovery of the noble gases

↑ **Parent:** [Noble gas](noble-gas.md)

Discovering them was not so easy because they don't form [chemical compounds](chemical-compound.md). So they exist only as gases. And [Helium](helium.md) disperses off into space.

[Argon](argon.md) was the first to be found by density considerations because it is so abundant on [Earth's atmosphere](atmosphere-of-earth.md) (~1%): [Argon is abundant on Earth's atmosphere because it comes from the decay of Potassium-40](argon-is-abundant-on-earth-s-atmosphere-because-it-comes-from-the-decay-of-potassium-40.md).

Then basically all of the others were discovered by [spectral lines](spectral-line.md). [Helium](helium.md) notably was first found on the [Sun](sun.md) like that, and only later on Earth! Thus its name. Pretty cool.
