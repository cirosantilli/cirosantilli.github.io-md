# Bare metal

↑ **Parent:** [Operating system](operating-system.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Bare_machine)

Bare metal programming is to run a program without an [operating system](operating-system.md) below it.

Or in other words, it is basically implementing an [operating system](operating-system.md)/[firmware](firmware.md) yourself ad hoc, together with your actual program.
