# Quantum algorithm

↑ **Parent:** [Quantum computing](quantum-computing-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Quantum_algorithm)

This is the true key question: what are the most important algorithms that would be accelerated by quantum computing?

Some candidates:
- [Shor's algorithm](shor-s-algorithm.md): this one will actually make humanity worse off, as we will be forced into [post-quantum cryptography](post-quantum-cryptography.md) that will likely be less efficient than existing classical [cryptography](cryptography-split.md) to implement
- [quantum algorithm for linear systems of equations](quantum-algorithm-for-linear-systems-of-equations.md), and related [application of systems of linear equations](application-of-systems-of-linear-equations.md)
- [Grover's algorithm](grover-s-algorithm.md): speedup not exponential. Still useful for anything?
- [Quantum Fourier transform](https://en.wikipedia.org/wiki/Quantum_Fourier_transform): TODO is the speedup exponential or not?
- Deutsch: solves an useless problem
- [NISQ algorithms](nisq-algorithm.md)

Do you have proper optimization or [quantum chemistry](quantum-chemistry.md) algorithms that will make trillions?

Maybe there is some room for doubt because some applications might be way better in some [implementations](quantum-computer-physical-implementation.md), but we should at least have a good general idea.

However, clear information on this really hard to come by, not sure why.
