# MacOS

↑ **Parent:** [Apple Inc product](apple-inc-product.md)  
🏷️ **Tags:** [Closed source offline software used by millions](closed-source-offline-software-used-by-millions.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/MacOS)

Nice looking and expensive operating system by [Apple](apple-inc-split.md). [Ciro Santilli](ciro-santilli-split.md) believes that:
- if you want to be ripped off, just use [Microsoft Windows](microsoft-windows.md) which has more software available
- or if you want to attain [Enlightenment](ourbigbook-com/motivation.md), just use [Linux](linux.md), which is free and open source

The story of how OS X was ported to x86 from PowerPC with large initial work up to boot by a single man in the year 2000, John Kullmann, is really worth reading: [https://www.quora.com/Apple-company/How-does-Apple-keep-secrets-so-well/answer/Kim-Scheinberg](https://www.quora.com/Apple-company/How-does-Apple-keep-secrets-so-well/answer/Kim-Scheinberg) on [Quora](quora.md), see also:
