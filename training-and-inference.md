# Training and inference

↑ **Parent:** [Supervised learning](supervised-learning.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Training_and_inference)

This is the first thing you have to know about [supervised learning](supervised-learning.md):
- training is when you learn model parameters from input. This literally means learning the best value we can for a bunch of number input numbers of the model. This can easily be on the hundreds of thousands.
- inference is when we take a trained model (i.e. with the parameters determined), and apply it to new inputs
Both of those already have [hardware acceleration](application-specific-integrated-circuit.md) available as of the 2010s.
