# Skelet machine \#1 is infinite

↑ **Parent:** [Skelet machine \#1](skelet-machine-1.md)

Non formal proof with a program March 2023: [https://www.sligocki.com/2023/03/13/skelet-1-infinite.html](https://www.sligocki.com/2023/03/13/skelet-1-infinite.html) Awesome article that describes the proof procedure.

[Formal proof](formal-proof.md) August 2023: [https://discuss.bbchallenge.org/t/skelet-1-is-a-translated-cycler-coq-agrees/166](https://discuss.bbchallenge.org/t/skelet-1-is-a-translated-cycler-coq-agrees/166)

The proof uses [Turing machine acceleration](turing-machine-acceleration.md) to show that [Skelet machine \#1](skelet-machine-1.md) is a [Translated cycler Turing machine](translated-cycler-turing-machine.md) with humongous cycle paramters:
- start between 50-200 M steps, not calculated precisely on the original post
- period: ~8 billion steps
