# Dimension (system of units)

↑ **Parent:** [Unit of measurement](unit-of-measurement.md)

A dimension in a [system of units](system-of-units-split.md) is something like [length](length.md), [weight](weight.md) or [time](time.md), without considering how to assign numerical values ot them, which requires [units of measurement](unit-of-measurement.md) such as the [meter](meter.md), [kilogram](kilogram.md) or [second](second.md).

Talking about dimensions can be useful when explaining new derived units without worrying about the exact units involved. See e.g. this table: [https://en.wikipedia.org/w/index.php?title=Lumen_(unit)&oldid=1233810964#SI_photometric_units](https://en.wikipedia.org/w/index.php?title=Lumen_(unit)&oldid=1233810964#SI_photometric_units)
