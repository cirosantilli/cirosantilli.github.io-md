# Collatz conjecture failure mode

↑ **Parent:** [Collatz conjecture](collatz-conjecture.md)

There are to ways in which the [Collatz conjecture](collatz-conjecture.md) can fail:
- [Collatz cycle](collatz-cycle.md): there is a cycle that loops forever and never reaches 1
- [Unbounded Collatz trajectory](unbounded-collatz-trajectory.md): there is a sequence that grows without bound without looping
These are the only two options because if any sequence has an upper bound, it must sooner or later repeat an element, leading to a cycle.
