# Levi-Civita symbol as a tensor

↑ **Parent:** [Levi-Civita symbol](levi-civita-symbol.md)  
🏷️ **Tags:** [Tensor](tensor.md)

[An Introduction to Tensors and Group Theory for Physicists by Nadir Jeevanjee (2011)](an-introduction-to-tensors-and-group-theory-for-physicists-by-nadir-jeevanjee-2011.md) shows that this is a [tensor](tensor.md) that represents the [volume of a parallelepiped](volume-of-the-parallelepiped.md).

It takes as input three vectors, and outputs one real number, the volume. And it is linear on each vector. This perfectly satisfied the definition of a tensor of [order](order-of-a-tensor.md) (3,0).

Given a basis $(e_i, e_j, e_k)$ and a function that return the volume of a parallelepiped given by three vectors $V(v_1, v_2, v_3)$, $\varepsilon_{ikj} = V(e_i, e_j, e_k)$.
