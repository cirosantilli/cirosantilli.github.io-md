# Project Euler solutions

↑ **Parent:** [Project Euler](project-euler-split.md)

Repositories of numerical solutions:
- [https://github.com/lucky-bai/projecteuler-solutions](https://github.com/lucky-bai/projecteuler-solutions)
- [https://www.kaggle.com/datasets/dheerajmpai/projecteuler](https://www.kaggle.com/datasets/dheerajmpai/projecteuler)

Repositories of code solutions:
- [https://euler.stephan-brumme.com/](https://euler.stephan-brumme.com/) large number of solutions in [C++](c-plus-plus.md), stopped around 600. Informal permissive license, e.g. at: [https://euler.stephan-brumme.com/243/](https://euler.stephan-brumme.com/243/)> I hope you enjoy my code and learn something - or give me feedback how I can improve my solutions.
  > 
  > All of my solutions can be used for any purpose and I am in no way liable for any damages caused.
  > 
  > You can even remove my name and claim it's yours. But then you shall burn in hell.

  Asked for a more formal open license at: [https://github.com/stbrumme/euler/issues/7](https://github.com/stbrumme/euler/issues/7)
- [https://www.ivl-projecteuler.com/home](https://www.ivl-projecteuler.com/home) 330+ solutions in [Python](python-programming-language.md) as of 2025. Random looking problem selection. On GitHub: [https://github.com/igorvanloo/Project-Euler-Explained](https://github.com/igorvanloo/Project-Euler-Explained) under [Unlicense](unlicense.md) license, a [public domain](public-domain.md) license.
- [https://www.nayuki.io/page/project-euler-solutions](https://www.nayuki.io/page/project-euler-solutions). Large number of solutions, mostly in [Java](java-programming-language.md) and	[Python](python-programming-language.md) primarily but also [Mathematica](wolfram-mathematica.md) and [Haskell](haskell.md) sometimes. Proprietary license.

Repositories with hints but no solutions:
- [https://github.com/RodericGuigoCorominas/project-euler](https://github.com/RodericGuigoCorominas/project-euler)

Basically no one has ever had the patience to create a single source that solves them all, all the above were done by individuals and stopped at some point. What we need is either a collaborative solution, or... [LLMs](large-language-model.md).
