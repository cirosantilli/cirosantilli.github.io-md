# Middle name

↑ **Parent:** [Personal name](personal-name.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Middle_name)

Middle names are a weird custom.

It's like a semi-secret part of your name that you only randomly use sometimes, and usually only in initials, and which no one else knows except your family.

It is as if the [Anglo-Saxons](anglo-saxons.md) were preparing for a real world [Death Note](https://ourbigbook.com/go/topic/death-note) attack [I know your true name](i-know-your-true-name.md)-style.
