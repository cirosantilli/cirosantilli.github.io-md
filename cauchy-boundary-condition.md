# Cauchy boundary condition

↑ **Parent:** [Neumann boundary condition](neumann-boundary-condition.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cauchy_boundary_condition)

Sets both a [Dirichlet boundary condition](dirichlet-boundary-condition.md) and a [Neumann boundary condition](neumann-boundary-condition.md) for a single part of the boundary.

Can be used for [hyperbolic partial differential equations](hyperbolic-partial-differential-equation.md).

We understand intuitively that this imposes stricter requirements on solutions, which makes it easier to guarantee uniqueness, but also harder to have existence. TODO intuitively why hyperbolic need this extra level of restriction.
