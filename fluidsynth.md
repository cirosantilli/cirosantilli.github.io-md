# FluidSynth

↑ **Parent:** [Software synthesizer](software-synthesizer.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/FluidSynth)

Synthesizes MIDI input. [vmpk](vmpk.md) + `aconnect` + [Advanced Linux Sound Architecture](advanced-linux-sound-architecture.md) [hello world](hello-world-program.md): [https://askubuntu.com/questions/34391/virtual-midi-piano-keyboard-setup/1298026#1298026](https://askubuntu.com/questions/34391/virtual-midi-piano-keyboard-setup/1298026#1298026)

Supports only very basic effects it seems: [chorus effect](chorus-effect.md) and [reverberation](reverberation.md). The main way to add instruments to it is via [SoundFont](soundfont.md) files.
