# Cycle notation

↑ **Parent:** [Permutation](permutation.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Cycle_notation)

A concise to describe a specific [permutation](permutation.md).

A permutation group can then be described in terms of the [generating set of a group](generating-set-of-a-group.md) of specific elements given in cycle notation.

E.g. [https://en.wikipedia.org/w/index.php?title=Mathieu_group&oldid=1034060469#Permutation_groups](https://en.wikipedia.org/w/index.php?title=Mathieu_group&oldid=1034060469#Permutation_groups) mentions that the [Mathieu group $M_{11}$](mathieu-group-m-11.md) is generated by three elements:
- (0123456789a)
- (0b)(1a)(25)(37)(48)(69)
- (26a7)(3945)
which feels quite compact for a [simple group](simple-group.md) with 95040 elements, doesn't it!
