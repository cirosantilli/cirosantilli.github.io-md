# Ring (mathematics)

↑ **Parent:** [Group](group-split.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Ring_(mathematics))

A [Ring](ring-mathematics.md) can be seen as a generalization of a [field](field-mathematics.md) where:
- multiplication is not necessarily [commutative](commutative-property.md). If this is satisfied, we can call it a [commutative ring](commutative-ring.md).
- multiplication may not have [inverse elements](inverse-element.md). If this is satisfied, we can call it a [division ring](division-ring.md).

Addition however has to be [commutative](commutative-property.md) and have inverses, i.e. it is an [Abelian group](abelian-group.md).

The simplest example of a ring which is not a full fledged [field](field-mathematics.md) and with [commutative](commutative-property.md) multiplication are the [integers](integer.md). Notably, no inverses exist except for the identity itself and -1. E.g. the inverse of 2 would be 1/2 which is not in the [set](set-mathematics.md). More specifically, the [integers](integer.md) are a [commutative ring](commutative-ring.md).

A [polynomial ring](polynomial-ring.md) is another example with the same properties as the [integers](integer.md).

The simplest [non-commutative](commutative-ring.md), [non-division](division-ring.md) is is the set of all 2x2 [matrices](matrix.md) of [real numbers](real-number.md):
- we know that 2x2 matrix multiplication is non-commutative in general
- some 2x2 matrices have a multiplicative inverse, but others don't
Note that [$GL(n)$](general-linear-group.md) is not a ring because you can by addition reach the zero matrix.
