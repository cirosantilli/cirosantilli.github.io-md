# Keep debug notes

↑ **Parent:** [Ciro Santilli's software engineering wisdom](ciro-santilli-s-software-engineering-wisdom.md)  
🏷️ **Tags:** [Debugging](debugging.md)

When [debugging](debugging.md) complex software, make sure to keep notes of every interesting find you make in a note file, as you extract it from the [integrated development environment](integrated-development-environment.md) or [debugger](debugger.md).

Especially if your [memory sucks like Ciro's](ciro-santilli-s-bad-old-event-memory.md).

This is incredibly helpful in fully understanding and then solving complex bugs.
