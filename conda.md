# Conda

↑ **Parent:** [Python package manager](python-package-manager.md)  
🏷️ **Tags:** [Evil](evil.md), [Python virtualization](python-virtualization.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Conda)

Conda is like [pip](pip-package-manager.md), except that it also manages shared library dependencies, including providing prebuilts.

This has made [Conda](conda.md) very popular in the [deep learning](deep-learning.md) community around 2020, where using Python frontends like [PyTorch](pytorch.md) to configure faster precompiled backends was extremely common.

It also means that it is a full package manager and extremely overbloated and blows up all the time. People should just use [Docker](docker-software.md) instead for that kind of stuff: [https://www.reddit.com/r/learnmachinelearning/comments/kd88p8/comment/keco07k/](https://www.reddit.com/r/learnmachinelearning/comments/kd88p8/comment/keco07k/)

You also have to buy a license to use their repos if you are part of a large-enough organization: [https://stackoverflow.com/questions/74762863/are-conda-miniconda-and-anaconda-free-to-use-and-open-source](https://stackoverflow.com/questions/74762863/are-conda-miniconda-and-anaconda-free-to-use-and-open-source)
