# Matrix exponential

↑ **Parent:** [Exponential function](exponential-function.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/Matrix_exponential)

Is the solution to a [system of linear ordinary differential equations](system-of-linear-ordinary-differential-equations.md), the [exponential function](exponential-function.md) is just a 1-dimensional subcase.

Note that more generally, the [matrix exponential](matrix-exponential.md) can be defined on any [ring](ring-mathematics.md).

The matrix exponential is of particular interest in the study of [Lie groups](lie-group.md), because in the case of the [Lie algebra of a matrix Lie group](lie-algebra-of-a-matrix-lie-group.md), it provides the correct [exponential map](exponential-map.md).
