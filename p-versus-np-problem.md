# P versus NP problem

↑ **Parent:** [NP-complete](np-complete.md)  
ⓦ [Wiki](https://en.wikipedia.org/wiki/P_versus_NP_problem)

Interesting because of the [Cook-Levin theorem](cook-levin-theorem.md): if only a single [NP-complete](np-complete.md) problem were in [P](p-complexity.md), then all NP-complete problems would also be P!

We all know the answer for this: either false or [independent](independence-mathematical-logic.md).
