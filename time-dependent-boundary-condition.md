# Time dependent boundary condition

↑ **Parent:** [Boundary condition](boundary-condition.md)

Most commonly, [boundary conditions](boundary-condition.md) such as the [Dirichlet boundary condition](dirichlet-boundary-condition.md) are taken to be fixed values in time.

But it also makes sense to think about cases where those values vary in time.
