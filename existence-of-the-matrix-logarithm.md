# Existence of the matrix logarithm

↑ **Parent:** [Logarithm of a matrix](logarithm-of-a-matrix.md)

[https://en.wikipedia.org/wiki/Logarithm_of_a_matrix#Existence](https://en.wikipedia.org/wiki/Logarithm_of_a_matrix#Existence) mentions it always exists for all [invertible](invertible.md) [complex](complex-number.md) matrices. But the [real](real-number.md) condition is more complicated. Notable counter example: -1 cannot be reached by any real $e^{tk}$.

The [Lie algebra exponential covering problem](lie-algebra-exponential-covering-problem.md) can be seen as a generalized version of this problem, because
- [Lie algebra](lie-algebra.md) of [$GL(n)$](general-linear-group.md) is just the entire [$M_n$](matrix-ring.md)
- we can immediately exclude non-invertible matrices from being the result of the exponential, because $e^{tM}$ has inverse $e^{-tM}$, so we already know that non-invertible matrices are not reachable
